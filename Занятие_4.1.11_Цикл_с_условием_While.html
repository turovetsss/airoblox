0 Теория: цикл while

🔄 Что такое while?

while значит «пока». Тело цикла повторяется, пока условие истинно (true). Когда условие стало false — цикл останавливается.

local dots = 3
while dots > 0 do
  print("Ещё есть точки!")
  dots = dots - 1
end
print("Точек не осталось")
ЧастьЗачем
while условие doПроверка перед каждым кругом
endКонец тела цикла
while true do«Двигатель» уровня — крутится всегда (стены Pac-Man)
💡 Внутри долгого while почти всегда нужен wait() или task.wait() — иначе Studio зависнет.

🚪 while в лабиринте

Дверь крутится, пока угол меньше нужного. Стена едет, пока не дошла до края. Стрела летит, пока Z меньше лимита.

while wall.Orientation.Y < 0 do
  wall.CFrame = wall.CFrame * CFrame.Angles(0, math.rad(2), 0)
  wait()
end

🔁 repeat … until

Похож на while, но проверка в конце: тело выполнится хотя бы один раз, потом «пока не выполнится условие».

local t = 0
repeat
  t = t + 0.1
  wait(0.1)
until t >= 2

🧱 Фаза 0 — Лабиринт и имена 12 мин

  1. Baseplate. Поставь SpawnLocation.
  2. Собери простой лабиринт из Part (стены Anchored = true, цвет синий).
  3. Оставь 2–3 коридора. В конце коридора Part имени Finish (зелёный).
  4. Создай Part WallDoor — «дверь» в проходе (жёлтый).
  5. Part WallSlide — узкая стена, которая будет ездить.
  6. Part SecretBox (оранжевый) + внутри ClickDetector.
  7. Part ArrowTemplate (красный, маленький) — шаблон стрелы. Anchored.
  8. Part Trap — платформа в полу коридора.
  9. Папка в Workspace: PacMan — положи туда все эти объекты (по желанию).
⚠️ Имена должны совпасть с кодом: WallDoor, WallSlide, SecretBox, ArrowTemplate, Trap, Finish.

🚪 Фаза 1 — Дверь WallDoor (while) 10 мин

Script внутри WallDoor (или в ServerScriptService, но тогда путь к Part пропиши сам).

local wall = script.Parent

while true do
  -- открываем (крутим в одну сторону)
  while wall.Orientation.Y > -90 do
    wall.CFrame = wall.CFrame * CFrame.Angles(0, math.rad(-2), 0)
    wait()
  end
  wait(1)
  -- закрываем
  while wall.Orientation.Y < 0 do
    wall.CFrame = wall.CFrame * CFrame.Angles(0, math.rad(2), 0)
    wait()
  end
  wait(1)
end
Если дверь крутится не туда — поменяй знаки у math.rad(+2) / (-2). Pivot двери лучше по краю (Edit Pivot).

↔️ Фаза 2 — Едущая стена WallSlide 10 мин

Script в WallSlide. Подгони числа X под свою карту (посмотри Position в Properties).

local part = script.Parent
local minX = part.Position.X - 8
local maxX = part.Position.X

while true do
  while part.Position.X > minX do
    part.CFrame = part.CFrame * CFrame.new(-0.2, 0, 0)
    wait()
  end
  while part.Position.X < maxX do
    part.CFrame = part.CFrame * CFrame.new(0.2, 0, 0)
    wait()
  end
end

📦 Фаза 3 — Секретный бокс 8 мин

local box = script.Parent
local click = box:WaitForChild("ClickDetector")

click.MouseClick:Connect(function()
  while box.Position.Y > box.Position.Y - 6 do
    -- лучше зафиксировать цель один раз:
    break -- см. надёжный вариант ниже
  end
end)

Надёжный скрипт (скопируй этот):

local box = script.Parent
local click = box:WaitForChild("ClickDetector")
local busy = false

click.MouseClick:Connect(function()
  if busy then return end
  busy = true
  local targetY = box.Position.Y - 6
  while box.Position.Y > targetY do
    box.CFrame = box.CFrame * CFrame.new(0, -0.2, 0)
    wait()
  end
end)

🏹 Фаза 4 — Стрела-призрак 8 мин

Script рядом с шаблоном (например в ServerScriptService) или в Part-спавнере. Шаблон ArrowTemplate лучше сделать прозрачным или спрятать в стороне.

local template = workspace:WaitForChild("ArrowTemplate")
template.Transparency = 1
template.CanCollide = false

while true do
  local arrow = template:Clone()
  arrow.Transparency = 0
  arrow.CanCollide = true
  arrow.Parent = workspace
  arrow.CFrame = template.CFrame
  local startZ = arrow.Position.Z
  while math.abs(arrow.Position.Z - startZ) < 40 do
    arrow.CFrame = arrow.CFrame * CFrame.new(0, 0, -0.8)
    wait()
  end
  arrow:Destroy()
  wait(2)
end
💡 Направление полёта: если стрела летит не в коридор — смени ось (X вместо Z) или знак.

☠️ Фаза 5 — Ловушка Trap (repeat) 8 мин

local trap = script.Parent
local startY = trap.Position.Y

while true do
  wait(3) -- стоит спокойно
  local t = 0
  repeat
    trap.CFrame = trap.CFrame * CFrame.new(0, -0.25, 0)
    t = t + 0.1
    wait(0.1)
  until t >= 2
  wait(1)
  -- вернуть наверх
  while trap.Position.Y < startY do
    trap.CFrame = trap.CFrame * CFrame.new(0, 0.25, 0)
    wait()
  end
end

🏆 Фаза 6 — Экран победы 10 мин

  1. StarterGui → ScreenGui имя WinGui.
  2. Внутри TextLabel на весь экран: текст YOU WIN! PAC-MAN, фон тёмный, Enabled у Gui пока false (или Visible = false у Frame).
  3. Удобнее: Frame WinFrame Visible = false, TextLabel внутри.

Script в ServerScriptService (или в Finish):

local finish = workspace:WaitForChild("Finish")

finish.Touched:Connect(function(hit)
  local player = game.Players:GetPlayerFromCharacter(hit.Parent)
  if not player then return end
  local gui = player.PlayerGui:FindFirstChild("WinGui")
  if gui then
    local frame = gui:FindFirstChild("WinFrame")
    if frame then frame.Visible = true end
  end
end)

Если GUI не находится с сервера — сделай LocalScript в WinGui, который слушает RemoteEvent. Для урока достаточно простого варианта: Script в Finish + Frame в StarterGui с Visible.

Простой учебный вариант (LocalScript в WinGui):

local finish = workspace:WaitForChild("Finish")
local frame = script.Parent:WaitForChild("WinFrame")
frame.Visible = false

finish.Touched:Connect(function(hit)
  local char = game.Players.LocalPlayer.Character
  if hit.Parent == char then
    frame.Visible = true
  end
end)
🏁 Мини-игра считается готовой, когда в Play ты сам проходишь лабиринт и видишь победу.
