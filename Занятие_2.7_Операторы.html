0 Теория: что такое операторы?

Оператор — это знак (или слово) в коде, который говорит компьютеру, что сделать с числами, текстом или условиями. Без операторов нельзя ни посчитать очки, ни спросить «хватает ли их для двери».

арифметика Арифметические операторы

Считают числа — как калькулятор. В пещере ими мы прибавляем очки за кристалл.

ОператорДействиеПримерРезультатВ игре
+Сложение30 + 2050Подобрал кристалл
-Вычитание50 - 1040Штраф / ловушка
*Умножение10 * 220Двойные очки
/Деление20 / 210Пополам
^Степень2 ^ 38Супер-буст
%Остаток10 % 31Чёт / нечёт
local score = 30
local points = 20
score = score + points -- стало 50
print(score)
⚠️
Скобки важны! Сначала умножение и деление, потом сложение (как в математике).
(10 + 10) * 2 = 40 · а 10 + 10 * 2 = 30.

сравнение Операторы сравнения

Отвечают true (да) или false (нет). Ими дверь спрашивает: «очков уже хватает?»

ОператорВопросПримерРезультат
==Равно?50 == 50true
~=Не равно?50 ~= 40true
<Меньше?40 < 50true
>Больше?60 > 50true
<=Меньше или равно?50 <= 50true
>=Больше или равно?score >= 50true / false
💡
Самая частая ошибка!
= — положить в переменную: score = 0
== — спросить «равно ли?»: if score == 50 then
В условиях почти всегда нужны ==, >=, <… а не одиночный =.
local need = 50
if score >= need then
  print("Очков хватает!")
else
  print("Собери ещё кристаллы")
end

логика Логические операторы

Склеивают несколько условий. В пещере дверь открывается только если хватает очков и есть ключ.

  • and — оба условия true → результат true
  • or — хотя бы одно true → true
  • not — переворачивает: not false → true
true and true → true ✅
true or false → true ✅
not false → true ✅
true and false → false ❌
false or false → false ❌
not true → false ❌
local enough = score >= 50
local hasKey = true
if enough and hasKey then
  print("Дверь открыта!")
end

В нашей игре: 80 очков без ключа → дверь закрыта (and не пропускает). Ключ без очков → тоже закрыта.

строки Склейка текста ..

Оператор .. (две точки) соединяет строки. Удобно для сообщений в Output:

print("Очки: " .. score) -- Очки: 50

Чем отличается = от ==?

= записывает значение, == спрашивает «равно ли?»
Они делают одно и то же
== только для текста, = только для чисел

При if score >= 50 and hasKey then дверь откроется, когда:

score = 50, hasKey = true

🏗️ Фаза 0 — Строим пещеру 18 мин

Все игровые объекты сложи в папку Cave в Workspace. У деталей поставь Anchored = true.

1. Стены и пол

  • Пол: Part ≈ 40×1×40.
  • Стены по краям (высота 15–20), оставь проём ~8×10 под дверь.
  • Можно Terrain или обычные Part + камни из Toolbox.

2. SpawnLocation

Внутри пещеры: Model → SpawnLocation — игрок появится здесь.

3. Door

В проёме Part ≈ 1×8×6, имя Door, цвет Really black.

4. Кристаллы Crystal1…Crystal5

5× Part, Shape = Ball, Material = Neon, разные цвета. Разбросай по пещере.

5. Key

Маленький жёлтый Neon Part, имя Key.

6. Score и HasKey

В папке Cave: IntValue → имя Score, Value = 0. BoolValue → имя HasKey, Value = false.

📦
Выдели Cave → + в Explorer → IntValue / BoolValue → переименуй.
📁 Cave
  🚪 Door
  💎 Crystal1 … Crystal5
  🔑 Key
  📊 Score (IntValue = 0)
  ✅ HasKey (BoolValue = false)

💎 Фаза 1 — Кристалл даёт очки (+) 16 мин

В каждый кристалл добавь Script CollectScript. Наступил → очки + → кристалл исчез.

-- CollectScript внутри кристалла
local crystal = script.Parent
local score = workspace.Cave.Score
local points = 10 -- сила этого кристалла

crystal.Touched:Connect(function(hit)
  if hit.Parent:FindFirstChild("Humanoid") then
    score.Value = score.Value + points
    print("Очки: " .. score.Value)
    crystal:Destroy()
  end
end)
✨
Разная сила: Crystal1–2 → 10 · Crystal3 → 20 · Crystal4 → 15 · Crystal5 → 30.
Максимум: 10+10+20+15+30 = 85. Для двери нужно 50.
📖 Кристалл не работает?
  • Папка называется именно Cave, IntValue — Score.
  • Скрипт лежит внутри кристалла.
  • Anchored = true. Смотри View → Output на красные ошибки.

🚪 Фаза 2 — Дверь по очкам (>=) 12 мин

В ServerScriptService создай DoorScript. Пока проверяем только очки (ключ добавим в следующей фазе).

-- DoorScript (версия 1: только очки)
local door = workspace.Cave.Door
local score = workspace.Cave.Score
local need = 50

while true do
  wait(0.5)
  if score.Value >= need then
    door.Transparency = 0.8
    door.CanCollide = false
    door.BrickColor = BrickColor.new("Bright green")
  else
    door.Transparency = 0
    door.CanCollide = true
    door.BrickColor = BrickColor.new("Really black")
  end
end

🔑 Фаза 3 — Ключ и and 13 мин

В Part Key — Script KeyScript:

-- KeyScript внутри Key
local key = script.Parent
local hasKey = workspace.Cave.HasKey

key.Touched:Connect(function(hit)
  if hit.Parent:FindFirstChild("Humanoid") then
    hasKey.Value = true
    print("Ключ получен!")
    key:Destroy()
  end
end)

Замени весь DoorScript на версию с and:

-- DoorScript (версия 2: очки AND ключ)
local door = workspace.Cave.Door
local score = workspace.Cave.Score
local hasKey = workspace.Cave.HasKey
local need = 50

while true do
  wait(0.5)
  local enough = score.Value >= need
  if enough and hasKey.Value then
    door.Transparency = 0.8
    door.CanCollide = false
    door.BrickColor = BrickColor.new("Bright green")
  else
    door.Transparency = 0
    door.CanCollide = true
    door.BrickColor = BrickColor.new("Really black")
  end
end
🎉 Готово! В одной игре ты использовал + , >= , and и склейку строк ..
📁 Cave — Door, Crystal1–5 (+ CollectScript), Key (+ KeyScript), Score, HasKey
📁 ServerScriptService — DoorScript
