1 Команды для добычи ресурсов

Агент может не только строить, но и добывать ресурсы! Для этого есть специальные команды:

🔨 Разрушить блок
agent.destroy(НАПРАВЛЕНИЕ)
Разрушает блок в указанном направлении
Пример: agent.destroy(DOWN)
🎁 Выдать предмет
agent.give(ПРЕДМЕТ, КОЛИЧЕСТВО, СЛОТ)
Добавляет предмет прямо в инвентарь Агента
Пример: agent.give(IRON_INGOT, 1, 1)
🔍 Проверить блок
agent.inspect(НАПРАВЛЕНИЕ)
Возвращает информацию о блоке перед Агентом
Пример: agent.inspect(DOWN)
🗑️ Выбросить предмет
agent.drop(НАПРАВЛЕНИЕ)
Выбрасывает предмет из инвентаря Агента
Пример: agent.drop(FORWARD)
⚠️ Очень важно! Когда Агент ломает блок командой destroy, блок НЕ выпадает в мир, как у игрока — он просто исчезает! Поэтому команда agent.collect() здесь не поможет.

Чтобы Агент «положил добычу к себе в инвентарь», нужно использовать agent.give() — она добавляет предмет напрямую, без выпадения в мир.

Проверка блока перед добычей

Чтобы Агент добывал только ценные блоки, нужно проверить, что за блок перед ним. Для этого используется команда agent.inspect(), которая возвращает ID блока.

check_block.py 
# Проверяем блок перед Агентом
block = agent.inspect(DOWN)

if block == 15:  # ID железной руды
    player.say("Нашёл железную руду!")
    agent.destroy(DOWN)
    agent.give(IRON_INGOT, 1, 1)  # Кладём слиток в инвентарь!
elif block == 56:  # ID алмазной руды
    player.say("Нашёл алмазы!")
    agent.destroy(DOWN)
    agent.give(DIAMOND, 1, 1)  # Кладём алмаз в инвентарь!
else:
    agent.destroy(DOWN)  # Просто копаем

3 Мини-проект: Шахта с ценными рудами

Теперь давай создадим программу, которая научит Агента копать шахту и собирать только ценные ресурсы!

🎯 Задача: Агент должен копать шахту вниз, проверять каждый блок, и если находит ценную руду (железо, золото, алмазы, изумруды) — разрушать её и добавлять в инвентарь через agent.give(). Обычные блоки (камень, земля) просто разрушать.
miner.py 
# Программа для Агента-шахтёра
# Агент копает вниз и добавляет ценные руды в инвентарь

def mine_shaft():
    for i in range(20):  # Копаем 20 блоков вниз
        block = agent.inspect(DOWN)  # Проверяем блок под Агентом
        
        # Проверяем, ценная ли руда
        if block == 15:  # Железная руда
            player.say("Нашёл железо!")
            agent.destroy(DOWN)
            agent.give(RAW_IRON, 1, 1)   # Необработанный слиток в инвентарь
        elif block == 14:  # Золотая руда
            player.say("Нашёл золото!")
            agent.destroy(DOWN)
            agent.give(RAW_GOLD, 1, 1)   # Необработанный слиток в инвентарь
        elif block == 56:  # Алмазная руда
            player.say("Нашёл алмазы!")
            agent.destroy(DOWN)
            agent.give(DIAMOND, 1, 1)      # Алмаз в инвентарь
        elif block == 133:  # Изумрудная руда
            player.say("Нашёл изумруды!")
            agent.destroy(DOWN)
            agent.give(EMERALD, 1, 1)      # Изумруд в инвентарь
        else:
            agent.destroy(DOWN)  # Обычный блок - просто копаем
        
        agent.move(DOWN, 1)  # Спускаемся на 1 блок вниз
    
    player.say("Шахта готова!")

# Привязываем к команде чата
player.on_chat("шахта", mine_shaft)

⭐ Бонус: Переплавка руды

Агент может проверить свой инвентарь и «переплавить» руду — то есть заменить её на слиток. В Minecraft Education это можно сделать так: проверяем слот, если там железная руда — забираем её и выдаём железный слиток.

smelt.py 
# Бонус: программа для переплавки руды
# Агент проверяет инвентарь и заменяет руду на слитки

def smelt_inventory():
    # Проверяем каждый слот инвентаря (у Агента 27 слотов)
    for slot in range(27):
        item = agent.get_item(slot)  # Получаем предмет из слота
        
        # Если это железная руда (ID 15)
        # Или если это необработанный слиток (ID 505)
        if item == 15:
            player.say("Переплавляю железо...")
            agent.drop(1)                     # Выбрасываем руду
            agent.give(IRON_INGOT, 1, slot)  # Кладём слиток на то же место
        
        # Если это золотая руда (ID 14)
        # Или если это необработанный слиток (ID 506)
        elif item == 14:
            player.say("Переплавляю золото...")
            agent.drop(1)
            agent.give(GOLD_INGOT, 1, slot)
    
    player.say("Переплавка завершена!")

player.on_chat("переплавь", smelt_inventory)
💡 Пояснение: команда agent.get_item(slot) возвращает ID предмета в указанном слоте инвентаря Агента (от 0 до 26). Мы проходим по всем слотам, и если находим руду — заменяем её на слиток через drop + give.
