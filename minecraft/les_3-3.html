Представь, что у тебя есть коробка с наклейкой «Мои игрушки». Ты можешь:

💡 Главная идея: переменные позволяют сохранять информацию и использовать её в разных местах программы. Если нужно изменить число — меняешь его в одном месте, а не во всей программе!

2 Типы данных

В переменные можно сохранять разные виды информации. Это называется тип данных.

ТипЧто хранитПримерыИспользование
Число
number		 Любые числа 10, -5, 3.14, 100 Счётчики, координаты, количество
Текст
string		 Строка символов "Привет", "Алекс", "Minecraft" Имена, сообщения, названия
Логический
boolean		 Правда или ложь true, false Условия, флаги, переключатели

3 Создание и изменение переменных

Как создать переменную?

В Minecraft Education для создания переменной используется кнопка создать переменную во вкладке Переменные.

создание_переменных.makecode

Как изменить переменную?

Чтобы изменить значение переменной, используется блок «изменить [имя] на [значение]».

изменение_переменных.makecode

Пример: счётчик шагов

счётчик_шагов.makecode
📌 Важно: переменные создаются один раз, а затем их можно изменять сколько угодно раз. В Minecraft Education блок «задать» создаёт переменную, а блок «изменить» меняет её значение.

🛠️ Практический проект: Строитель с переменными

Выполнено шагов: 0 из 6

Создай программу, которая строит башню, используя переменные для управления размерами.

Пошаговый проект:

  • Используй вложенный цикл: внешний повторить ширина раз, внутренний повторить ширина раз [поставить блок; двигаться вперёд]
  • После каждого квадрата агент должен подняться вверх
  • Используй блок изменить счётчик_этажей на 1 внутри цикла строительства
💡 Подсказка: переменные позволяют легко менять размеры башни. Попробуй изменить высота на 10 или ширина на 4 — и башня изменится автоматически!
