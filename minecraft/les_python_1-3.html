1 Что такое условные операторы?

В жизни мы постоянно принимаем решения: «Если идёт дождь, я возьму зонтик», «Если я голоден, я поем». В программировании тоже есть такие решения — это условные операторы.

🤔 Условный оператор — это конструкция, которая позволяет программе выполнять разные действия в зависимости от выполнения условия.

2 Операторы if, else, elif

В Python есть три основных условных оператора. Давай разберём их на примерах из Minecraft!

1. Оператор if — «Если»

Проверяет условие. Если оно верно (True), выполняет команды внутри блока.

if_demo.py 
# Если игрок онлайн — приветствуем
is_online = True
if is_online:
    player.say("Добро пожаловать!")

2. Оператор else — «Иначе»

Выполняется, если условие в if неверно (False).

if_else_demo.py 
# Проверяем, день или ночь
is_day = True
if is_day:
    player.say("Доброе утро!")
else:
    player.say("Спокойной ночи!")

3. Оператор elif — «Иначе если»

Позволяет проверить несколько условий подряд. Сокращение от "else if".

elif_demo.py 
# Проверяем время суток
time = 12
if time < 12:
    player.say("Доброе утро!")
elif time < 18:
    player.say("Добрый день!")
else:
    player.say("Добрый вечер!")
⚠️ Важно! После if, elif и else всегда ставится двоеточие :, а блок кода внутри должен иметь отступ (4 пробела или Tab).

3 Операции сравнения

Чтобы проверить условия, мы используем операции сравнения. Вот основные из них:

ОперацияЗначениеПример
==Равноage == 10 — возраст равен 10
!=Не равноname != "Алекс" — имя не Алекс
>Большеcount > 5 — количество больше 5
<Меньшеcount < 10 — количество меньше 10
>=Больше или равноscore >= 100 — очков не меньше 100
<=Меньше или равноscore <= 50 — очков не больше 50
comparison_demo.py 
# Примеры сравнений в Minecraft
block_count = 15

if block_count >= 10:
    player.say("У тебя много блоков!")

player_name = "Алекс"
if player_name == "Алекс":
    player.say("Привет, Алекс!")
else:
    player.say("Привет, гость!")
