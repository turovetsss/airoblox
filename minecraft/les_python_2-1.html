1 Кто такой Агент?

Агент — это твой верный помощник в Minecraft Education. Это маленький робот, который может выполнять твои команды: ходить, строить, разрушать блоки и даже собирать предметы.

🤖 Агент — это программируемый робот. Ты можешь давать ему команды с помощью Python, и он будет их выполнять в игровом мире.
🚶
Движение
Агент умеет ходить вперёд, назад, влево, вправо, вверх и вниз
🔄
Повороты
Может поворачиваться налево и направо
🧱
Строительство
Ставит и разрушает блоки по команде

2 Команды движения

Чтобы Агент двигался, мы используем команду agent.move(). Ей нужно передать два параметра: направление и количество шагов.

agent_move.py 
# Движение Агента
agent.move(FORWARD, 5)   # Пройти вперёд 5 шагов
agent.move(BACK, 3)       # Пройти назад 3 шага
agent.move(LEFT, 2)        # Пройти влево 2 шага
agent.move(RIGHT, 4)       # Пройти вправо 4 шага
agent.move(UP, 1)          # Подняться на 1 блок вверх
agent.move(DOWN, 1)        # Опуститься на 1 блок вниз

3 Повороты

Агент может поворачиваться на 90 градусов влево или вправо с помощью команды agent.turn().

agent_turn.py 
# Повороты Агента
agent.turn(LEFT)   # Повернуть налево
agent.turn(RIGHT)  # Повернуть направо

# Пример: квадрат
for i in range(4):
    agent.move(FORWARD, 5)
    agent.turn(RIGHT)
💡 Важно! После поворота Агент меняет своё направление, и все следующие команды движения будут выполняться относительно нового направления.

4 Блоки: поставить и сломать

Агент умеет ставить и разрушать блоки с помощью команд agent.place() и agent.destroy().

🧱 Поставить блок
agent.place(FORWARD)
Ставит блок перед Агентом (из инвентаря)
🔨 Сломать блок
agent.destroy(FORWARD)
Разрушает блок перед Агентом
📦 Поставить с направлением
agent.place(DOWN)
Ставит блок под Агентом
📦 Сломать с направлением
agent.destroy(UP)
Разрушает блок над Агентом
agent_build.py 
# Агент строит башню
for i in range(5):
    agent.place(DOWN)     # Ставит блок под собой
    agent.move(UP, 1)       # Поднимается на блок вверх

🧠 Найди ошибку в коде Агента

В каждом уровне есть ровно одна ошибка. Кликни на строку с ошибкой!

Уровень 1: Неправильное направление

agent_error_1.py 
agent.move(FRW✅, 5)
💡 Подсказка: Проверь правильность написания направления. Название должно быть на английском.

Уровень 2: Пропущена команда place

agent_error_2.py 
agent.(FORWARD)✅
💡 Подсказка: Для установки блока нужна команда place.

Уровень 3: Неправильное количество шагов

agent_error_3.py 
agent.move(FORWARD, "5"✅)
💡 Подсказка: Количество шагов должно быть числом, без кавычек.
