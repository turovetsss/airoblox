🌀 Что происходит в мире?

Ты находишь зачарованное яблоко — странный предмет. Когда игрок использует его (ПКМ / взаимодействие), перед ним внезапно вырастает куб из случайных блоков размером 16 × 16 × 16 — как будто открылась «изнанка» мира.

4096 блоков — мощная магия! Не злоупотребляй.

⚠️ Важно для занятия
  • Работай в своём отдельном мире (или один ученик — один мир). Если несколько человек запустят эффект в одном мире, игра может сильно лагать.
  • В чате могут появляться сообщения вроде «этот блок является предметом и его нельзя поставить» — это нормально: часть ID — не блоки. На занятии можно не исправлять, программа всё равно строит куб.
  • Готовое решение — только через кнопку с паролем от преподавателя. Сначала попробуй сам!

1 Событие: использование предмета

Раньше мы запускали код по команде в чате. Здесь код запускается, когда игрок использует конкретный предмет.

🍎 player.on_item_interacted
player.on_item_interacted(ENCHANTED_APPLE, on_item_interacted)
Вызывает функцию on_item_interacted, когда игрок использует зачарованное яблоко. В начале файла нужна функция с этим именем (без параметров).
📍 player.position()
posP = player.position()
Сохраняет текущую позицию игрока. Из неё можно взять X, Y, Z через get_value(Axis.X) и т.д.
🎲 randint
randint(0, 800)
Случайное целое число от 0 до 800 — будем использовать как ID блока.
🧱 blocks.block_by_id
blocks.block_by_id(42)
Превращает число (ID) в тип блока для команды blocks.place.
item_event_skeleton.py 
def on_item_interacted():
    player.say("Что-то странное начинается...")

player.on_item_interacted(ENCHANTED_APPLE, on_item_interacted)
💡 Предмет в инвентаре: выдай себе зачарованное яблоко через творческий режим или команду в чате, иначе протестировать не получится.

2 Строим куб 16×16×16

Чанк в Minecraft часто ассоциируют с размером 16 блоков. Нам нужно перебрать все комбинации x, y, z от 0 до 15 — для этого подходит тройной вложенный цикл for.

triple_loop.py 
for x in range(16):
    for y in range(16):
        for z in range(16):
            # здесь: выбрать случайный блок и поставить его в world(...)
            pass

Где строить? Возьми координаты игрока и сдвинь угол куба, например на +10 по X и +10 по Z — чтобы куб появился рядом, а не внутри игрока. Каждый блок внутри цикла:

world(posX + x, posY + y, posZ + z)

📐 Связь с занятием 2.3: здесь мы снова используем world() — абсолютные координаты. Угол куба считаем один раз; в цикле только прибавляем x, y, z.

🧩 Расставь шаги алгоритма

Выбери правильный порядок (1 — первый, 5 — последний):

? Зарегистрировать обработчик: яблоко → функция
? Получить позицию игрока и вычислить угол куба (posX, posY, posZ)
? Тройной цикл for по x, y, z от 0 до 15
? Внутри цикла: случайный ID → block_by_id → blocks.place в world(...)
? Объявить функцию on_item_interacted (внутри неё вся логика)

Подсказка: в Python сначала пишут функцию, потом регистрируют событие внизу файла.

Шаг 3 Угол куба

Сохрани player.position(), вычисли posX, posY, posZ через get_value(Axis.X) и сдвинь X и Z вперёд (например +10).

Шаг 4 Тройной цикл

Три вложенных for с range(16). Счётчики: x, y, z.

Шаг 5 Случайный блок

Внутри цикла: block = blocks.block_by_id(randint(0, 800)). Ошибки в чате про «предмет» можно игнорировать.

Шаг 6 Поставить блок

blocks.place(block, world(posX + x, posY + y, posZ + z)). Запусти один раз в своём мире — куб большой, подожди завершения.
