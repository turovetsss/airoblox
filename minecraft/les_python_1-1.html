0 Как работают компьютеры?

Прежде чем говорить о программировании, давай разберёмся, что такое компьютер и как он «понимает» наши команды.

От электричества к информации

Внутри компьютера миллиарды крошечных переключателей — транзисторов. Они могут быть либо включены (1), либо выключены (0). Компьютер «думает» с помощью таких сигналов — это называется двоичный код.

💡 Интересный факт: Любая информация в компьютере — текст, картинки, видео — это просто последовательности нулей и единиц. Например, буква «A» в двоичном коде выглядит как 01000001.

Как люди общаются с компьютером?

Люди говорят на разных языках — русском, английском, китайском. Компьютеры понимают только машинный код — последовательности нулей и единиц. Но программистам было бы очень сложно писать программы в таком виде. Поэтому люди придумали языки программирования — мосты между человеческим языком и машинным кодом.

Человек ➡️ Язык программирования ➡️ Машинный код (0 и 1)

1 История языков программирования

Языки программирования развивались вместе с компьютерами. Давай посмотрим на главные вехи:

1940-е
Машинный код — программисты писали программы напрямую нулями и единицами. Это было очень сложно и медленно.
1950-е
Ассемблер — появились первые сокращения (мнемоники) для команд. Вместо 0101 можно было написать ADD.
1957
FORTRAN — первый высокоуровневый язык. Учёные могли писать формулы почти как в математике.
1972
C — мощный язык, который до сих пор используется для создания операционных систем и игр.
1991
Python — язык, который создали, чтобы программирование было простым и понятным. Именно его мы будем изучать!
Машинный код → Ассемблер → FORTRAN → C → Python 🐍
🚀 Почему Python?
Python создали, чтобы программирование было понятным и доступным. Его код похож на обычный английский язык, поэтому его легко читать и писать. Не зря говорят: «Python — это исполняемый псевдокод».

2 Что такое Python?

До сих пор мы собирали программы из блоков, как конструктор LEGO. Это круто, чтобы понять логику, но настоящие программисты пишут код текстом. И один из самых крутых языков для этого — Python (Пайтон).

Python — это мощный, но при этом простой для чтения язык. Его используют в:
  • Создании игр (да-да, и в Minecraft тоже!)
  • Искусственном интеллекте (ChatGPT написан с помощью Python)
  • Научных исследованиях и космосе
  • Создании сайтов и приложений (YouTube, Instagram)

3 Как это выглядит?

Давайте сравним, как одна и та же задача выглядит в блоках и на Python.

Пример 1: Команда чата «jump»

Когда мы пишем в чат jump, игрок подлетает вверх.

🧩 Блоки

🐍 Python

jump.py 
def on_chat_jump():
    player.teleport(pos(0, 10, 0))
player.on_chat("jump", on_chat_jump)
🎬 Результат: Игрок подлетает вверх при команде /jump

Пример 2: Команда чата «turn»

По команде чата turn все золотые блоки в радиусе превращаются в камень.

🧩 Блоки

🐍 Python

turn.py 
def on_chat_turn():
    blocks.replace(GOLD_BLOCK, STONE, pos(-10, 0, -10), pos(10, 10, 10))
player.on_chat("turn", on_chat_turn)
🎬 Результат: Все золотые блоки в области становятся камнем
💡 Важно: В Python мы создаём функцию (def), а затем привязываем её к команде чата с помощью player.on_chat(). Это и есть настоящая программная инженерия!

6 Правила написания (Синтаксис)

Компьютер очень внимателен к деталям. Если ты совершишь ошибку в «грамматике» кода, он не поймет команду. Вот главные правила:

1. Отступы (Indentation)
В Python отступы показывают, какие команды относятся к функции. Если команда «внутри» функции, перед ней должно быть 4 пробела (или клавиша Tab).
✅ Правильно 
def hello():
    # ← Этот отступ (4 пробела) показывает, что команда внутри функции
    player.say("Привет!")
❌ Ошибка 
def hello():
    # ← Нет отступа — Python выдаст ошибку!
player.say("Привет!")
2. Названия функций
Функции начинаются со слова def (от английского define — определить). После названия обязательно идут скобки () и двоеточие :.
✅ Правильно 
def my_function():  # ← def, название, скобки, двоеточие
    player.say("Hello!")
3. Скобки и кавычки
Аргументы команды пишутся внутри (). Текст — в "кавычках".
✅ Правильно 
player.say("Привет, мир!")  # ← Текст в кавычках
agent.move(FORWARD, 5)      # ← Аргументы в скобках
