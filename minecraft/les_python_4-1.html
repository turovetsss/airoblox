🧠 Что такое искусственный интеллект?

Искусственный интеллект (ИИ) — это когда компьютер или программа выполняет задачи, для которых обычно нужен человеческий «ум»: узнавать картинки, понимать речь, подсказывать маршрут, отвечать на вопросы.

ИИ не «магия» и не робот с чувствами — это алгоритмы: чёткие правила и данные. Чем больше примеров видит система, тем лучше она справляется. Голосовые помощники, рекомендации в видео и умная камера на телефоне — всё это разные формы ИИ.

На этом курсе мы сначала учимся думать как программисты: собирать логику из шагов. Агент в Minecraft, который сам идёт и записывает, что видит под ногами, — маленькая модель «исследователя»: он повторяет одно и то же действие, пока не встретит преграду, и в конце выдаёт отчёт. Позже мы будем пользоваться настоящими ИИ-помощниками (например, Алисой), чтобы быстрее разбираться в коде — но основа всегда в твоих решениях и типах данных.

1 Типы данных и зачем их указывать

В Python (и в Minecraft Education) в одной переменной может лежать текст, число или да/нет. От типа зависит, что можно делать: числа складывают, строки — склеивают, логические значения — проверяют в if и while.

str
"трава", "Отчёт:"
Строка — текст в кавычках
number
0, 5, amount
Число — счётчики шагов, ID
bool
True, False
Игра идёт? game = True

В нашем проекте в функции отчёта мы явно пишем, какие типы ждём — это называется аннотация типов (подсказка для тебя и для редактора):

types_in_function.py 
def show_report(trail: str, steps: number):
    # trail — длинная строка с названиями блоков
    # steps — сколько шагов прошёл агент
    player.say("Шагов: " + str(steps))
💡 Имя функции: в учебном примере иногда пишут print, но в Python это встроенная команда. Лучше назвать функцию show_report или finish_explore, чтобы не путаться.

Зачем указывать типы?

  • Ты сразу видишь: сюда придёт текст, сюда — число.
  • Меньше ошибок вроде "5" + 3 (строка + число без str()).
  • В больших проектах так проще читать чужой код — как подписи на коробках.

2 Алгоритм «Агент-исследователь»

Задача: программа работает, пока перед агентом нет блока. На каждом шаге агент смотрит, какой блок под ним, добавляет название в строку result, делает шаг вперёд и увеличивает счётчик. Когда впереди стена — цикл останавливается и вызывается функция с отчётом.

🧱 agent.detect
agent.detect(AgentDetection.BLOCK, FORWARD)
Возвращает True, если впереди есть блок (преграда).
👇 agent.inspect_block
block = agent.inspect_block(DOWN)
Число-ID блока под агентом. 0 — «блока нет».
🏷️ blocks.name_of_block
blocks.name_of_block(block)
Превращает ID в читаемое имя для отчёта (строка).
🚶 agent.move
agent.move(FORWARD, 1)
Один шаг вперёд после записи блока.
explorer_base.py 
def show_report(a: str, b: number):
    player.say("Результат:")
    player.say(a)
    player.say("Блоков пройдено: " + str(b))
    player.say("Закончили :)")

amount = 0
result = ""
block = AIR
game = True

while game:
    if agent.detect(AgentDetection.BLOCK, FORWARD):
        game = False
        show_report(result, amount)
    block = agent.inspect_block(DOWN)
    if block == 0:
        player.say("Блока нету :(")
    else:
        result = "" + result + blocks.name_of_block(block) + ", "
    agent.move(FORWARD, 1)
    amount += 1
🗺️ Полигон для теста: построй ровную дорожку из разных блоков и поставь в конце стену на уровне глаз агента. Вызови агента, поверни его лицом к дорожке и запусти код (C → Run).

3 Как сделать программу «красочнее»

Базовый код уже работает — улучшения не меняют идею, а делают игру понятнее и интереснее:

  • Старт и финиш — короткие сообщения от player.say и agent.say («миссия началась», «финиш»).
  • Красивый отчёт — разделители, подписи «Маршрут», «Шагов» вместо одной строки.
  • Прогресс — каждые 5 шагов писать в чат «уже N шагов».
  • Голос агента — иногда озвучивать имя блока через agent.say, не на каждом шаге (иначе спам).
  • Разделители в строке — вместо запятых использовать → или · , чтобы список читался.

Готовый «улучшенный» вариант — за паролем преподавателя в конце практики. Сначала собери базовую версию сам!
