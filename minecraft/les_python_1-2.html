1 Что такое переменная?

Представь, что ты играешь в Minecraft и тебе нужно запомнить, сколько у тебя алмазов. Ты можешь записать это на листочке. В программировании для этого есть переменные.

📦 Переменная — это как коробка с именем, в которую можно положить какие-то данные (число, текст, и т.д.) и потом использовать их в программе.
Имя переменной
player_name
=
Значение
"Алекс"
⬅️ Переменная хранит текст

Как объявить переменную в Python?

В Python объявить переменную очень просто — нужно придумать имя и присвоить ей значение через знак =.

variables.py 
# Объявление переменных
player_name = "Алекс"          # Текст (строка)
player_age = 12               # Целое число
is_online = True             # Логическое значение (правда)
speed = 5.5                 # Число с плавающей точкой

# Использование переменной
player.say("Привет, я " + player_name)

2 Типы данных

В Python данные бывают разных видов. Это называется типами данных. Представь, что у тебя есть коробки для разных вещей: для книг, для игрушек, для еды. Так и в программировании — для разных данных есть свои типы.

Основные типы данных в Python

int
age = 12
Целые числа
без дробной части
float
speed = 5.5
Числа с плавающей точкой
с дробной частью
str
name = "Алекс"
Строки (текст)
в кавычках
bool
is_online = True
Логический тип
True (правда) или False (ложь)

Зачем нужны типы данных?

Типы данных нужны, чтобы компьютер знал, как обрабатывать информацию. Например, с числами можно складывать, а с текстом — соединять (склеивать).

types_demo.py 
# Работа с разными типами данных
# Числа
count = 10
new_count = count + 5      # 15

# Строки (текст)
name = "Алекс"
greeting = "Привет, " + name   # "Привет, Алекс"

# Логический тип
is_day = True
if is_day:
    player.say("Доброе утро!")
⚠️ Важно! Нельзя складывать числа и текст напрямую. Python выдаст ошибку!
age = 12 — число, age + " лет" — ❌ ошибка!
str(age) + " лет" — ✅ правильно (преобразуем число в текст)

3 Правила именования переменных

Придумывая имя для переменной, нужно соблюдать правила. Представь, что ты подписываешь коробку — имя должно быть понятным и правильным.

✅ Правильные имена
player_name
age
speed
is_online
Понятные, на английском, с подчёркиванием
❌ Неправильные имена
1player — нельзя начинать с цифры
player name — нельзя использовать пробел
def — зарезервированное слово
Имя_игрока — лучше использовать английский
Начинаются с цифры, содержат пробелы, используют зарезервированные слова
📌 Правила для имён переменных в Python:
  • Имя может содержать только буквы (a-z, A-Z), цифры (0-9) и подчёркивание (_)
  • Имя не может начинаться с цифры
  • Имя не может содержать пробелы (используй подчёркивание)
  • Используй осмысленные имена — чтобы было понятно, что хранит переменная
  • В Python принято использовать строчные буквы и подчёркивание: player_name, block_count
  • Нельзя использовать зарезервированные слова (ключевые слова Python): if, for, def, while, True, False и другие
