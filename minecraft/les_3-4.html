💡 Важно: переменные создаются один раз, а затем их можно изменять. В Minecraft Education переменные создаются через кнопку "Создать переменную" во вкладке Переменные.

🛠️ Практические задания: строим с переменными

Выполнено заданий: 0 из 7

Запусти Minecraft Education и выполни задания, используя переменные для управления строительством.

1 Квадрат с переменной стороной

Внешний цикл: повторить сторона раз, внутренний: повторить сторона раз [поставить блок; двигаться вперёд]

2 Прямоугольник с разными сторонами

Внешний цикл: повторить высота раз, внутренний: повторить ширина раз [поставить блок; двигаться вперёд]

3 Башня с переменной высотой

Сначала построй квадрат 3×3, затем подняться вверх. Всё это оберни в цикл повторить этажи раз

4 Ступеньки с переменным размером

Используй вложенный цикл, где количество повторений внутреннего цикла зависит от номера шага.
повторить ступени раз [
  повторить [номер_шага] раз [поставить блок; двигаться вперёд]
  повернуть налево; двигаться вперёд; повернуть налево
]

5 Пирамида с переменным размером

Создай переменную текущий_размер = размер.
В цикле: построй квадрат текущий_размер×текущий_размер, затем изменить текущий_размер на -2, подняться вверх.
Повторяй, пока текущий_размер > 0

⭐ Бонус 6: Дом с переменными

Стены: заполни область от (0, 64, 0) до (ширина_дома, 64 + высота_дома, ширина_дома) материалом.
Крыша: заполни область от (0, 64 + высота_дома, 0) до (ширина_дома, 64 + высота_дома + 1, ширина_дома) деревом.
Окна и дверь размести вручную.

⭐ Бонус 7: Город с переменными

Создай программу, которая в цикле строит дом, затем перемещается на расстояние блоков вперёд и строит следующий дом.
Используй переменную счётчик для отслеживания количества построенных домов.
💡 Совет: меняй значения переменных и смотри, как меняются постройки. Это главное преимущество переменных — легко изменять размеры, не переписывая весь код!
