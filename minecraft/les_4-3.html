1 Сюжет: Добыча с умом

⛏️ Обычный шахтёр копает прямо вниз — и часто пропускает богатые жилы руды.

Шахтёр-стратег действует иначе: перед каждым ударом кирки он сканирует 3 блока впереди — слева, по центру и справа. Если видит уголь, железо или алмаз — копает туда. Если руды нет — спускается вниз.

Когда рюкзак полон — агент возвращается на базу по сохранённым координатам.

🔍 chooseDirection() → ⛏️ digStep() → 📊 depth + oreCount → 🏠 домой, если полон инвентарь
🔗 Связь с прошлыми занятиями: копание мы учили в 2.3, координаты — в 3.1–3.3, функции — в 4.1, мини-проект — в 4.2. Сегодня добавляем return — функция «отдаёт» результат!

3 Новое: функция возвращает значение (return)

Раньше функции только делали действия. Теперь функция может ответить, что выбрала:

📤 return (вернуть) — в конце функции блок вернуть отдаёт текст или число тому, кто вызвал функцию.

Пример: направление = вызвать chooseDirection — переменная получит «вперёд», «влево», «вправо» или «вниз».
шахтер_алгоритм.txt 
-- При команде чата "шахта":
depth = 0
oreCount = 0
baseX, baseY, baseZ = позиция агента (абсолютные)

пока depth < 30:
    направление = вызвать chooseDirection
    вызвать digStep направление
    depth = depth + 1
    если инвентарь полон → телепорт (baseX, baseY, baseZ)

сказать "Глубина: " + depth + ", руда: " + oreCount

-- Функция chooseDirection:
если впереди руда → вернуть "вперёд"
иначе если слева руда → вернуть "влево"
иначе если справа руда → вернуть "вправо"
иначе → вернуть "вниз"
💡 Упрощение: на первом проходе достаточно проверить только блок впереди (~0 ~−1 ~1). Бонус — добавить сканирование слева и справа.

1 Подготовка и переменные

Координаты базы: блоки Positions → «позиция агента по X / Y / Z» (абсолютные числа). Сохрани их в переменные при старте программы.

2 Функция isOre() — есть ли руда?

Можно обойтись без отдельной функции: три проверки если ID блока в ~0 ~−1 ~1 = 16 прямо в chooseDirection. Функция isOre — для аккуратного кода.

3 Функция chooseDirection() — с return!

4 Функция digStep(направление)

После разрушения руды: изменить oreCount на 1. Для тоннеля высотой 2 блока: сначала разруши блок на уровне головы, потом на уровне ног (как в занятии 2.3).

5 Команда «шахта» и цикл «пока»

Блок «задать переменной значение вызова функции» — в Переменные. Цикл остановится, когда depth станет 30.
