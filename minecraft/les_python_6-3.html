Твоя собственная мини-игра в Minecraft — с планом и кодом

🎓 Финишная прямая курса

Ты прошёл Python в Minecraft: переменные, условия, агента, координаты, ИИ-помощников, функции, списки. Теперь — свой проект: маленькая игра или интерактив в мире, который придумываешь ты (с одобрением преподавателя).

📋 Что уже было на курсе

  • Python, чат, переменные
  • Условия и циклы
  • Агент: move, place
  • Координаты, fill
  • ИИ для кода
  • Функции, списки
  • Pixel Art

✅ Обязательные элементы проекта

Игра или сценарий должен явно использовать:

📦 Переменные
🔁 Циклы
🧩 Функции
📍 Координаты
Тема — только после согласования с преподавателем. ИИ (DeepSeek, ChatGPT, Алиса) можно для черновика кода и идей — но ты проверяешь и понимаешь каждую часть. Без личных данных в чатах.

2 Примеры тем (для вдохновения)

  • Мини-квест: найди блоки по подсказкам агента
  • «Слот» или лотерея
  • Стройка арены и PvE с мобами (безопасно, по правилам центра)
  • Паркур с телепортами по координатам
  • Сад: список блоков → ряд грядок
