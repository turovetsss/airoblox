1 Три способа строить в Python

🤖 Через Агента

Робот ходит и ставит блоки. Удобно для дорог, заборов, башен «по шагам».

📍 Через координаты

Команды blocks.place и blocks.fill сразу в точке мира — без ходьбы.

📦 Готовые объёмы

Заполнение куба, «полый» дом, контур — одной командой fill или циклом.

Без функций: мы ещё не проходим def как тему. Запускай код через команду чата — используй готовый шаблон в конце теории (скопируй и вставь свой код с отступом внутрь).

2 Строительство с Агентом

Повторение занятий 2.1–2.2. Агенту нужны блоки в инвентаре.

agent.move(НАПРАВЛЕНИЕ, шаги)
agent.move(FORWARD, 3)
FORWARD, BACK, LEFT, RIGHT, UP, DOWN
agent.turn(LEFT / RIGHT)
agent.turn(RIGHT)
Поворот на 90° — для квадратов и углов
agent.place(НАПРАВЛЕНИЕ)
agent.place(DOWN)
Блок под ногами — дорога; FORWARD — стена перед агентом
agent.destroy(НАПРАВЛЕНИЕ)
agent.destroy(FORWARD)
Убрать лишний блок перед стройкой
agent.teleport(pos, сторона)
agent.teleport(pos(0, 0, 3), NORTH)
Поставить агента рядом с игроком перед стартом
agent_road.py 
# Дорога из 8 блоков (вставь внутрь шаблона чата)
for i in range(8):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

3 Блоки по координатам

Из занятия 3.1: абсолютные world(x,y,z) и относительные pos(...), posCamera(...).

blocks.place
blocks.place(GRASS, world(5, 64, 5))
Один блок в точке
blocks.fill
blocks.fill(STONE, world(0,64,0), world(5,68,5), FillOperation.REPLACE)
Заполнить параллелепiped между двумя углами
FillOperation.HOLLOW
blocks.fill(..., FillOperation.HOLLOW)
Только стены — пусто внутри (домик, колодец)
FillOperation.OUTLINE
blocks.fill(..., FillOperation.OUTLINE)
Только рёбра куба — рамка
blocks.replace
blocks.replace(GRASS, STONE, pos(0,-1,0), pos(5,-1,5))
Заменить один тип блока на другой в области
player.position()
positions.add(player.position(), pos(2, 0, 2))
Строить «от игрока», не запоминая X, Y, Z наизусть
platform.py 
# Площадка 7×7 под игроком
blocks.fill(
    GRASS,
    pos(-3, -1, -3),
    pos(3, -1, 3),
    FillOperation.REPLACE
)

Выполнено шагов: 0 из 6
Шаг 1 Тема и план

Выбери карточку выше. Набросай на бумаге размеры и что делает агент, а что — fill/place.

Шаг 2 Шаблон чата

Скопируй шаблон player.on_chat("build", build) из части 4. Проверь: в чате build — появляется сообщение «Начинаю…».

Шаг 3 Основа постройки

Реализуй «скелет» (один fill, один цикл агента или линия place). Сначала без декора.

Шаг 4 Тест в мире

Запусти в своём плоском мире. Если смещено — поправь pos / телепорт агента.

Шаг 5 Детали

Добавь 2–3 детали: факел, другой блок, второй цвет, маленький забор и т.д.

Шаг 6 Показ преподавателю

Расскажи, почему выбрал агента или fill. Покажи работающую команду чата.
