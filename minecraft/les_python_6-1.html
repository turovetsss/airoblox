1 Что такое список?

Слово массив часто слышат в играх и математике. В Python мы говорим список (list) — упорядоченная коллекция значений в квадратных скобках.

Зачем? Не писать десять раз почти один и один код — храним блоки, высоты или команды в одном месте и перебираем циклом. В занятии 5.3 список items уже использовался для автомата.

list_basic.py
colors = [WOOL, ORANGE_WOOL, RED_WOOL]
# индекс с 0:
first = colors[0]
count = len(colors)   # 3

for i in range(len(colors)):
    player.say(str(i) + ": блок в списке")
Индекс: первый элемент — [0], последний — [len(list)-1]. Вариант for block in colors: тоже перебирает список без счётчика.

2 Список и строительство

Идея: список типов блоков + цикл, который ставит каждый блок со сдвигом по X или Z от игрока.

build_from_list.py
road = [STONE, COBBLESTONE, STONE, GRASS]

def build_road():
    start = player.position()
    for i in range(len(road)):
        spot = positions.add(start, pos(i + 1, 0, 0))
        blocks.place(road[i], spot)

player.on_chat("road", build_road)
