📊 Google Slides — структура

Открыть Google Slides

Войди через аккаунт, который дал преподаватель (школа / центр).

  • 1
    Титульный лист — название игры, твоё имя, «Курс Python + Minecraft · РОБОВИТА», дата.
  • 2
    Идея — о чём игра, для кого, как выиграть / что делает игрок (2–4 пункта).
  • 3
    Инструменты — что использовал: функции, циклы, переменные, координаты, при необходимости — агент, списки, ИИ, Pixel Art. Не просто список слов — по одному предложению «зачем».
  • 4
    Скриншот кода — обязательно фрагмент Python из Minecraft (главная функция или интересный цикл). Читаемый шрифт, можно обвести важное.
  • 5
    Скриншот геймплея — мир, постройка, момент игры.
  • 6+
    Дополнительно — второй скрин кода, «было / стало», планы на будущее (по желанию).
