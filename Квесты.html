Пин-код → двери-пустышки → тёмная комната с фонариком

Миссия проекта: собрать трёхэтапный квест. Сначала — дверь с пин-кодом 566. Потом — комната с цветными дверями-загадками (правильная — цвет неба). В финале — тёмная комната: включи фонарик и открой секретный выход.

💡 На этом проекте ты:

  • соберёшь цифровую панель на двери (Button1…9 + SurfaceGui) 🔢
  • сохранишь ввод в IntValue CurrentCode 💾
  • сделаешь GUI кода и двери-пустышки с RemoteEvent 🚪
  • включишь фонарик (PointLight) и уберёшь SecretDoor 🔦

📚 Теория: логика квеста

1. Три комнаты — три загадки

① Пин-код

Кнопки набирают число в CurrentCode. Ручка Open сверяет с секретом.

② Цветные двери

Правильный цвет — Bright blue (небо). Остальные кидают на Spawn.

③ Тёмная комната

Кликни FlashLight → свет → SecretDoor исчезает.

2. Как набирается код

Каждая кнопка делает: currentCode.Value = currentCode.Value * 10 + цифра.

Было 0 → жмём 5 → 5
Жмём 6 → 5×10+6 = 56
Жмём 6 → 56×10+6 = 566 ✅

3. IntValue и экран

CurrentCode в Workspace — общее хранилище кода. LocalScript смотрит на изменение Value и пишет цифры в CodeLabel.

Open → ClickDetector + Script.

-- Script внутри Open
local clickDetector = script.Parent:WaitForChild("ClickDetector")
local currentCode = workspace:WaitForChild("CurrentCode")
local door = workspace:WaitForChild("Door")
local SECRET_CODE = 566

clickDetector.MouseClick:Connect(function(player)
    print("Попытка открыть дверь, код: " .. currentCode.Value)
    if currentCode.Value == SECRET_CODE then
        door.Transparency = 0.5
        door.CanCollide = false
        print("Дверь открыта игроком " .. player.Name)
        local label = Instance.new("Message", workspace)
        label.Text = "Теперь найди правильную дверь!"
        wait(5)
        label:Destroy()
    else
        print("Неверный код от игрока " .. player.Name)
    end
    currentCode.Value = 0 -- сброс
end)
🎓 Секретный код 566 — можно сменить в строке SECRET_CODE. Ученикам код подсказывает педагог.

-- LocalScript в StarterPlayerScripts
local player = game.Players.LocalPlayer
local playerGui = player:WaitForChild("PlayerGui")
local screenGui = playerGui:WaitForChild("CodeScreen")
local codeLabel = screenGui:WaitForChild("CodeLabel")
local currentCode = workspace:WaitForChild("CurrentCode")

local function updateDisplay()
    local code = currentCode.Value
    if code == 0 then
        codeLabel.Text = "----"
    else
        codeLabel.Text = string.format("%03d", code)
    end
    print("Экран обновлён: " .. codeLabel.Text)
end

updateDisplay()
currentCode:GetPropertyChangedSignal("Value"):Connect(updateDisplay)

🎓 Правильная дверь: if doorColor == "Bright blue". Цвет Part в Properties → BrickColor = Bright blue.
-- Script внутри каждой цветной двери
local door = script.Parent
local doorColor = door.BrickColor.Name
local spawnLocation = workspace:WaitForChild("SpawnLocation")
local replicatedStorage = game:GetService("ReplicatedStorage")
local showMessageEvent = replicatedStorage:WaitForChild("ShowMessage")

door.Touched:Connect(function(hit)
    local character = hit.Parent
    local player = game.Players:GetPlayerFromCharacter(character)
    if not player then return end

    if doorColor == "Bright blue" then
        character:MoveTo(workspace.WinRoom.Position)
        local label = Instance.new("Message", workspace)
        label.Text = "Теперь найди, где включить свет в комнате!"
        wait(5)
        label:Destroy()
        showMessageEvent:FireClient(player, "Правильно!", "Цвет неба — синий! Ты прошёл!", 3)
    else
        character:MoveTo(spawnLocation.Position)
        showMessageEvent:FireClient(player, "Подумай ещё", "Это не цвет неба. Попробуй другую дверь!", 3)
    end
end)

-- Script внутри FlashLight
local flashlight = script.Parent
local clickDetector = flashlight:WaitForChild("ClickDetector")
local light = flashlight:WaitForChild("PointLight")
local door = workspace:WaitForChild("SecretDoor")
local replicatedStorage = game:GetService("ReplicatedStorage")
local showMessageEvent = replicatedStorage:WaitForChild("ShowMessage")

clickDetector.MouseClick:Connect(function(player)
    light.Enabled = true
    door.Transparency = 0
    door.CanCollide = true
    door:Destroy()
    showMessageEvent:FireClient(player, "Свет!", "Фонарик включён! Дверь появилась.", 2)
end)
