🧟
Операция «Лес Лиама»
Город пал под зомби-вирусом. Юный учёный Лиам укрылся в лесу и строит защиту из функций: один раз написал код — вызываешь снова и снова. Твоя задача — оживить ловушки, цветы, щиток и переключатель дня и ночи.

📖 История миссии

Глава 1. Ловушки в чаще

Лиам расставил платформы MovingBlock. Они должны подниматься и опускаться без конца. Если копировать один и тот же цикл дважды — код раздуется. Решение: функция move() и цикл while true.

Глава 2. Цветы-защитники

В лесу растут светящиеся цветы. При касании цветок растёт и отгоняет зомби. Нужна функция growth(flower) с аргументом — одна логика для любого цветка.

Глава 3. Электрический щиток

В доме щиток wiresGui: кнопки соединяют провода. Функции setPoint и click держат порядок — иначе кнопки начнут путаться.

Глава 4. День и ночь

Ночью зомби смелее. Кнопки в DayNight вызывают Day() и Night() и меняют освещение. Одна кнопка — один вызов функции.

📦 Что такое функция?

Функция — это именованный кусок кода, который можно вызвать сколько угодно раз. Без функций одно и то же приходится копировать. С функцией — написал один раз, вызываешь по имени.

local function sayHi()
  print("Привет, Лиам!")
end

sayHi() -- вызов
sayHi() -- ещё раз
ЧастьЗачем
function … endОбъявление функции
sayHi()Вызов — запуск тела функции

📥 Аргументы — данные «внутрь»

Аргумент — значение, которое ты передаёшь функции. Внутри функции это обычная переменная.

local function growth(flower)
  flower.Size = flower.Size + Vector3.new(0, 1, 0)
end

growth(flower1)
growth(flower2)
💡 Одна функция — много цветов. Меняется только аргумент.

↩️ return — результат «наружу»

return отдаёт значение туда, откуда функцию вызвали, и завершает функцию.

local function sum(a, b)
  return a + b
end

local s = sum(3, 4) -- s = 7

🧱 Фаза 1 — MovingBlock · функция move 12 мин

💡
Создай Script в каждый MovingBlock (внутри папки MovingBlocks). Рядом уже может быть Kill — не трогай его.
  1. Создай функцию move:
    • цикл for 25 раз: поднимать блок по Y, wait()
    • цикл for 25 раз: опускать блок по Y, wait()
  2. Напиши бесконечный цикл: вызвать move(), затем wait().
local function move()
  for i = 1, 25 do
    script.Parent.CFrame = script.Parent.CFrame * CFrame.new(0, 0.3, 0)
    wait()
  end
  for i = 1, 25 do
    script.Parent.CFrame = script.Parent.CFrame * CFrame.new(0, -0.3, 0)
    wait()
  end
end

while true do
  move()
  wait()
end

Если блок едет «не туда» — поменяй знаки у 0.3 / -0.3.

🌸 Фаза 2 — Flowers · growth(flower) 12 мин

Открой Script в модели Flowers (рядом ClickDetector).

  1. Создай 6 переменных: flower1 … flower6 = script.Parent.flower1 и т.д.
  2. Функция growth(flower):
    • while flower.Size.Y < 4.5 do
    • увеличить Size по Y на 0.05, wait(0.01)
    • после цикла: flower.CanTouch = true
  3. В ClickDetector.MouseClick вызови growth для каждого цветка.
local flower1 = script.Parent.flower1
local flower2 = script.Parent.flower2
local flower3 = script.Parent.flower3
local flower4 = script.Parent.flower4
local flower5 = script.Parent.flower5
local flower6 = script.Parent.flower6

local function growth(flower)
  while flower.Size.Y < 4.5 do
    flower.Size = flower.Size + Vector3.new(0, 0.05, 0)
    wait(0.01)
  end
  flower.CanTouch = true
end

script.Parent.ClickDetector.MouseClick:Connect(function()
  growth(flower1)
  growth(flower2)
  growth(flower3)
  growth(flower4)
  growth(flower5)
  growth(flower6)
end)

🔌 Фаза 3 — wiresGui · setPoint 10 мин

Открой LocalScript в StarterGui → wiresGui → Frame.

В начале скрипта (если ещё нет):

local GuiObjectA = nil
local GuiObjectB = nil
  1. Функция setPoint(btn):
    • если GuiObjectA == nil → GuiObjectA = btn
    • иначе → GuiObjectB = btn
-- Функция для установки точек
local function setPoint(btn)
  if GuiObjectA == nil then
    GuiObjectA = btn
  else
    GuiObjectB = btn
  end
end

🔌 Фаза 4 — функция click 10 мин

Продолжай тот же LocalScript.

  1. Создай функцию click.
  2. Если GuiObjectA ~= nil и GuiObjectB ~= nil — создай два вектора (откуда и куда рисовать линию) — как в заготовке карты / подсказке тренера.
local function click()
  if GuiObjectA ~= nil and GuiObjectB ~= nil then
    -- векторы и отрисовка линии (по шаблону на карте)
    local posA = GuiObjectA.AbsolutePosition + GuiObjectA.AbsoluteSize / 2
    local posB = GuiObjectB.AbsolutePosition + GuiObjectB.AbsoluteSize / 2
    -- дальше: создать/обновить линию между posA и posB
  end
end

🌙 Фаза 7 — функции Day и Night 12 мин

Script / LocalScript в DayNight:

  1. Day: script.Parent.Enabled = false → пока ClockTime < 14.5 увеличивай время на 0.05, wait → снова Enabled = true
  2. Night: то же до 23.9, затем ClockTime = 0, Enabled = true
  3. Привяжи к кнопкам: MouseButton1Click:Connect(Day) / Connect(Night)
local function Day()
  script.Parent.Enabled = false
  while game.Lighting.ClockTime < 14.5 do
    game.Lighting.ClockTime += 0.05
    wait()
  end
  script.Parent.Enabled = true
end

local function Night()
  script.Parent.Enabled = false
  while game.Lighting.ClockTime < 23.9 do
    game.Lighting.ClockTime += 0.05
    wait()
  end
  game.Lighting.ClockTime = 0
  script.Parent.Enabled = true
end

script.Parent.Day.MouseButton1Click:Connect(Day)
script.Parent.Night.MouseButton1Click:Connect(Night)
