✏️ TextBox — поле ввода

Игрок печатает текст с клавиатуры. В коде читаем свойство .Text.

СвойствоЗачем
TextТо, что сейчас в поле (то, что ввёл игрок)
PlaceholderTextПодсказка серым, пока поле пустое («Введи имя»)
ClearTextOnFocusСтирать текст при клике? Обычно false
TextScaledТекст подстраивается под размер поля
local nameBox = frame.NameBox
local name = nameBox.Text
print("Игрок написал: " .. name)

TextLabel

Только показать. Печатать нельзя.

TextBox

Можно кликнуть и набрать текст.

🖼️ ImageLabel — картинка без клика

Как TextLabel, только вместо текста — изображение.

  • Свойство Image — ссылка вида rbxassetid://123456789
  • ScaleType — Fit / Crop / Stretch (как вписать картинку)
  • Фон часто прозрачный: BackgroundTransparency = 1
📥
Откуда взять картинку?
1) Toolbox → Decals / Images → вставь → скопируй Texture / ID
2) Или загрузи свою через Asset Manager (Create → Image)
В свойство Image вставь: rbxassetid://НОМЕР

🖱️ ImageButton — кнопка-картинка

Как TextButton, но выглядит как картинка. Клик тот же:

imageButton.MouseButton1Click:Connect(function()
  print("Нажали на иконку!")
end)

ImageLabel

Картинка. Клик не нужен (логотип, аватар).

ImageButton

Картинка + клик (ок, закрыть, выбрать героя).

  2. Frame по центру (Visible = true).
  3. Внутри:
    • TextLabel Title — «Пропуск героя»

🖼️ Фаза 2 — Картинка для Avatar / GoBtn 10 мин

  1. Найди в Toolbox картинку (Decal / Image) или загрузи свою.
  2. Скопируй ID и вставь в Avatar.Image: rbxassetid://…
  3. Для GoBtn тоже поставь Image (стрелка / галочка) или оставь цветную кнопку с текстом «ГОТОВО».
⚠️
Если картинка не грузится — не страшно: сделай Avatar цветным квадратом, а GoBtn — ImageButton с текстом. Главное — TextBox и клик.

📜 Фаза 3 — LocalScript: имя + дверь 14 мин

LocalScript в HeroPass:

local gui = script.Parent
local frame = gui:WaitForChild("Frame")
local nameBox = frame:WaitForChild("NameBox")
local result = frame:WaitForChild("Result")
local goBtn = frame:WaitForChild("GoBtn")
local door = workspace.HQ:WaitForChild("Door")
local isOpen = door:WaitForChild("IsOpen")

goBtn.MouseButton1Click:Connect(function()
  local name = nameBox.Text
  if name == "" then
    result.Text = "Сначала введи имя!"
    return
  end
  result.Text = "Добро пожаловать, " .. name .. "!"
  isOpen.Value = true
  door.Transparency = 0.6
  door.CanCollide = false
end)
✏️
Ключ урока: nameBox.Text — то, что игрок напечатал. Пустая строка "" — проверка «не забыл ли имя».

🎭 Фаза 5 (доп) — Выбор иконки тремя ImageButton 10 мин

Добавь в Frame три ImageButton: Icon1, Icon2, Icon3 (разные картинки или цвета). По клику меняй Avatar.Image (или BackgroundColor3).

local avatar = frame.Avatar
frame.Icon1.MouseButton1Click:Connect(function()
  avatar.BackgroundColor3 = Color3.fromRGB(50, 200, 80)
end)
frame.Icon2.MouseButton1Click:Connect(function()
  avatar.BackgroundColor3 = Color3.fromRGB(50, 120, 255)
end)
frame.Icon3.MouseButton1Click:Connect(function()
  avatar.BackgroundColor3 = Color3.fromRGB(220, 80, 80)
end)

🧹 Фаза 6 (доп) — Кнопка «Очистить» 8 мин

TextButton или ImageButton ClearBtn: очищает NameBox и Result, закрывает дверь.

frame.ClearBtn.MouseButton1Click:Connect(function()
  nameBox.Text = ""
  result.Text = ""
  isOpen.Value = false
  door.Transparency = 0
  door.CanCollide = true
end)

🏰 Фаза 7 (доп) — Штаб за дверью 10 мин

  • За дверью — комната из Parts (пол + стены) или модель из Toolbox.
  • Внутри табличка SurfaceGui «ШТАБ» (повтор прошлого навыка — по желанию).
  • Всё декор в папке HQ.
