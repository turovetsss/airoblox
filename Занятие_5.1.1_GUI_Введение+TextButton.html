0 Теория: пользовательский интерфейс

🖱️ Что такое интерфейс (UI / GUI)?

UI (User Interface) — способ общения человека с программой. GUI (Graphical User Interface) — когда общение идёт через картинки и кнопки, а не только через текст в консоли.

В жизни GUI — это иконки на телефоне. В Roblox — полоска здоровья, магазин, меню паузы, кнопки «Играть».

💡
Зачем GUI в игре?
• показать информацию (счёт, таймер, HP)
• дать действие (купить, открыть дверь, выбрать ответ)
• сделать игру понятной без объяснений голосом

📁 Где создаётся GUI в Roblox?

Почти всё экранное меню лежит в StarterGui. При запуске игры содержимое копируется игроку в PlayerGui.

StarterGui → ScreenGui → Frame → TextButton / TextLabel
📁 StarterGui
  🖼️ ScreenGui ← «холст» на весь экран
    📦 Frame ← панель/окно
      📝 TextLabel ← надпись
      🔘 TextButton ← кнопка
      📜 LocalScript ← код реакции на клик
⚠️
Для кнопок на экране обычно нужен LocalScript (код на стороне игрока). Обычный Script в ServerScriptService экран игрока «не видит» так же удобно.

🔘 TextButton: реакция на клик

Самое важное событие — MouseButton1Click (левая кнопка мыши / тап):

local button = script.Parent.Frame.OpenButton

button.MouseButton1Click:Connect(function()
  print("Кнопка нажата!")
  script.Parent.Frame.Visible = false
end)

Один большой проект на урок. Пульт в мире → открывается GUI с тремя кнопками-паролями → правильный пароль открывает дверь, неправильный — закрывает меню.

🏗️ Фаза 1 — Модели в мире 12 мин

  1. В Workspace создай Part Door (Anchored). Цвет тёмный.
  2. Рядом Part Remote (пульт). Внутрь добавь ClickDetector.
  3. В Door добавь BoolValue с именем IsOpen, Value = false.

🖥️ Фаза 2 — Собираем GUI 15 мин

  1. В StarterGui создай ScreenGui → имя DoorGUI.
  2. Внутрь — Frame (по центру экрана, Size примерно {0.35,0},{0.4,0}).
  3. В Frame:
    • TextLabel Title — текст «Введи пароль»
    • TextButton Pass1 — текст 1234
    • TextButton Pass2 — текст 5678 (правильный!)
    • TextButton Pass3 — текст 9012
    • TextLabel Result — текст пустой
  4. В свойствах Frame сразу поставь Visible = false.

📜 Фаза 3 — LocalScript: показать меню 12 мин

В DoorGUI создай LocalScript. Сначала только открытие панели по клику на пульт:

local players = game:GetService("Players")
local player = players.LocalPlayer
local gui = script.Parent
local frame = gui:WaitForChild("Frame")
local remote = workspace:WaitForChild("Remote")

frame.Visible = false

remote.ClickDetector.MouseClick:Connect(function(clickPlayer)
  if clickPlayer == player then
    frame.Visible = true
  end
end)

🔑 Фаза 4 — Кнопки пароля + дверь 16 мин

Добавь в тот же LocalScript обработку кнопок. Правильный пароль — Pass2 (5678).

local door = workspace:WaitForChild("Door")
local isOpen = door:WaitForChild("IsOpen")
local result = frame:WaitForChild("Result")

local function closeGui()
  task.wait(1.5)
  frame.Visible = false
  result.Text = ""
end

frame.Pass2.MouseButton1Click:Connect(function()
  isOpen.Value = true
  door.Transparency = 0.7
  door.CanCollide = false
  result.Text = "Дверь открыта!"
  closeGui()
end)

local function wrong()
  result.Text = "Неверный пароль"
  closeGui()
end

frame.Pass1.MouseButton1Click:Connect(wrong)
frame.Pass3.MouseButton1Click:Connect(wrong)
💡
Если дверь не меняется с клиента, добавь в Door обычный Script на сервере:
door.IsOpen.Changed:Connect(function() ... Transparency / CanCollide ... end)
📖 Серверный Script для двери (если нужно)
local door = script.Parent
local isOpen = door.IsOpen

isOpen.Changed:Connect(function()
  if isOpen.Value then
    door.Transparency = 0.7
    door.CanCollide = false
  else
    door.Transparency = 0
    door.CanCollide = true
  end
end)

Тогда в LocalScript при верном пароле достаточно: isOpen.Value = true (через RemoteEvent — для продвинутых). На первом уроке GUI можно менять дверь прямо в LocalScript для теста.

❌ Фаза 6 (доп) — Кнопка «Закрыть» 8 мин

Иногда меню надо просто закрыть, без пароля. Добавь ещё одну TextButton.

  1. В Frame создай TextButton с именем CloseBtn.
  2. Текст: X или Закрыть. Поставь в правый верхний угол Frame.
  3. В LocalScript добавь клик:
frame.CloseBtn.MouseButton1Click:Connect(function()
  frame.Visible = false
  result.Text = ""
end)

🔒 Фаза 7 (доп) — Кнопка «Закрыть дверь» 8 мин

Пусть дверь можно закрыть обратно — ещё одна простая TextButton.

  1. В Frame создай TextButton LockBtn, текст Закрыть дверь.
  2. При клике верни дверь в закрытое состояние:
frame.LockBtn.MouseButton1Click:Connect(function()
  isOpen.Value = false
  door.Transparency = 0
  door.CanCollide = true
  result.Text = "Дверь закрыта"
  closeGui()
end)
💡
Та же идея, что у Pass2, только наоборот: IsOpen = false, дверь снова непрозрачная и непроходимая.

💬 Фаза 8 (доп) — Подсказка и свой пароль 10 мин

Простые улучшения без сложной логики — потренируй TextButton и TextLabel.

  1. Кнопка HintBtn с текстом ?. По клику в Result пиши подсказку, например: Правильный — средний (не раскрывай цифры сразу).
  2. Свой пароль: поменяй текст Pass2 на любой свой (например 8888). Главное — в скрипте по-прежнему срабатывает Pass2 (имя кнопки важнее надписи!).
  3. Цвета: Pass1 красная, Pass2 зелёная, Pass3 синяя — чтобы было видно, что это разные кнопки.
frame.HintBtn.MouseButton1Click:Connect(function()
  result.Text = "Подсказка: правильный — средний"
end)
