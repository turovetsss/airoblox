📡 Что такое событие?

Событие — это способ сказать коду: «Когда произойдёт X, выполни Y». Без событий скрипт просто «пробегает» сверху вниз один раз. С событием он ждёт действия игрока.

🦶 Touchedнаступил на Part
🖱️ ClickDetectorкликнул мышью
🔑 ProximityPromptподошёл и нажал E

Подписка всегда одинаковая: :Connect(function() … end).

-- схема: объект.Событие:Connect(функция)
чтоТо.Событие:Connect(function()
  -- что делать, когда событие случилось
end)

🦶 Touched — касание

Срабатывает, когда к Part прикасается другая деталь или персонаж. В параметр hit приходит то, что коснулось (часто нога игрока).

script.Parent.Touched:Connect(function(hit)
  if hit.Parent:FindFirstChild("Humanoid") then
    print("Игрок коснулся!")
  end
end)
ЭлементЗачем
hitPart, который коснулся (нога, рука…)
hit.ParentМодель персонажа
FindFirstChild("Humanoid")Проверка: это игрок, а не камень
💡
Без проверки Humanoid гриб может «собраться», если на него упадёт другая деталь.

⚡ Где правильно написано событие касания?

script.Parent.Touched:Connect(function(hit)
  
end)
script.Parent.Touched.Connect(function(hit)
  
end)
script.Parent.Touched:Conect(function(hit)
  
end)
script.Parent.Touched:Connect(hit()
  
end)

🖱️ ClickDetector — клик мыши

Сначала в Part через «+» в Explorer добавляют объект ClickDetector. Потом в скрипте слушают событие MouseClick.

script.Parent.ClickDetector.MouseClick:Connect(function()
  print("Клик по объекту!")
end)
✅ Нужно
Part → ClickDetector → Script
Событие: MouseClick
❌ Ошибка
Только Script без ClickDetector
Клик не сработает
ОсобенностьОписание
ОбъектClickDetector — прямой ребёнок Part
СобытиеMouseClick — левая кнопка мыши
⚠️
Без ClickDetector скрипту не к чему «подписаться» — клик просто игнорируется.

⚡ Где правильно написано событие клика?

script.Parent.ClickDetector.MouseClick:Connect(function()
  
end)
script.Parent.ClickDetector:Connect(function()
  
end)
script.Parent.ClickDetector.MouseClick(function()
  
end)
script.Parent.MouseClick:Connect(function()
  
end)

🔑 ProximityPrompt — взаимодействие рядом

Показывает игроку кнопку (обычно E), когда он подходит близко. Объект ProximityPrompt кладут внутрь Part. Событие — Triggered.

script.Parent.ProximityPrompt.Triggered:Connect(function()
  print("Взаимодействие!")
end)
ПараметрОписание
TriggeredСрабатывает, когда игрок нажал клавишу
КлавишаПо умолчанию E (можно сменить в Properties)

⚡ Где правильно написано ProximityPrompt?

script.Parent.ProximityPrompt.Triggered:Connect(function()
end)
script.Parent.ProximityPrompt:Connect(function()
end)
script.Parent.ProximityPrompt.Triggered(function()
end)
script.Parent.Triggered:Connect(function()
end)

✅ Три шаблона — сравни

Один и тот же приём: событие → Connect → function → end. Меняется только «когда».

-- 1. Касание
script.Parent.Touched:Connect(function(hit)
end)

-- 2. Клик
script.Parent.ClickDetector.MouseClick:Connect(function()
end)

-- 3. Клавиша E рядом
script.Parent.ProximityPrompt.Triggered:Connect(function()
end)

🧊 Фаза 4 — Лёд и ключ 8 мин

В объект Ice: ClickDetector + Script. Считай клики; когда count >= taps.Value — удали лёд.

local count = 0

script.Parent.ClickDetector.MouseClick:Connect(function()
  count = count + 1
  if count >= script.taps.Value then
    script.Parent:Destroy()
  end
end)
Выполнено шагов: 0 из 3
  • Значение taps — IntValue внутри скрипта или Ice. Проверь Explorer.

🚪 Фаза 5 — Locked_Door → домой 14 мин

В DoorBase внутри модели Locked_Door добавь : ProximityPrompt + Script. Если KeyRemove == true — сделай дверь и Hole1/Hole2 прозрачными без коллизии на 3 секунды, затем верни.

script.Parent.ProximityPrompt.Triggered:Connect(function()
  if script.Parent.Parent.KeyRemove.Value == true then
    script.Parent.Transparency = 1
    script.Parent.CanCollide = false
    script.Parent.Parent.Hole1.Transparency = 1
    script.Parent.Parent.Hole2.Transparency = 1
    script.Parent.Parent.Hole1.CanCollide = false
    script.Parent.Parent.Hole2.CanCollide = false
    wait(3)
    script.Parent.Transparency = 0
    script.Parent.CanCollide = true
    script.Parent.Parent.Hole1.Transparency = 0
    script.Parent.Parent.Hole2.Transparency = 0
    script.Parent.Parent.Hole1.CanCollide = true
    script.Parent.Parent.Hole2.CanCollide = true
  end
end)
Transparency = 1 — невидимо · CanCollide = false — можно пройти · wait(3) — пауза 3 секунды
