🏷️ BillboardGui

Метки в воздухе: теория → мини-игра → остров квестов

🧭
SurfaceGui лежит на стене. А имя над NPC, восклицательный знак над квестом, метка над сундуком? Это BillboardGui — табличка в мире, которая всегда смотрит на камеру.

🖥️ Три вида GUI — три места

ScreenGui

На экране игрока. Меню, HP, кнопки.

SurfaceGui

На грани Part. Вывеска, табло на стене.

BillboardGui

В воздухе над объектом, смотрит на камеру.

💡
Обойди объект кругом: SurfaceGui «прилип» к стороне, BillboardGui всё время поворачивается к тебе — как имя над головой в мультиках.

🧱 Как создать метку

  1. Выбери Part (или Head у NPC).
  2. Insert Object → BillboardGui.
  3. Внутрь → TextLabel (текст) или Frame + несколько Label.

У TextLabel внутри: Text, TextScaled = true, BackgroundTransparency = 1 (часто без фона).

🎯 Где вешать метку

  • Head — имя над NPC / игроком
  • Сундук / кристалл — «!» или «?» для квеста
  • Точка телепорта — «Вход»
📌
StudsOffset по Y поднимает текст выше объекта. Если метка «внутри» блока — увеличь Y (например с 1 до 3).

  1. Папка QuestIsland в Workspace.

🧑 Фаза 1 — NPC с именем 12 мин

  1. Сгенерируй NPC- вкладка Avatar - Character.
  2. В Head (или верхний Part) добавь BillboardGui → TextLabel.
  3. Текст: своё имя гида, например Капитан Робо.
  4. BillboardGui: Size ≈ {0,200},{0,50}, StudsOffset = 0, 2.5, 0, AlwaysOnTop = true, MaxDistance = 80.
🏷️
Обойди NPC кругом в Play — имя всегда читается лицом к тебе. Это и есть BillboardGui.

📦 Фаза 2 — Три сундука с «?» 12 мин

Создай 3 Part (коричневые): Chest1, Chest2, Chest3. На каждый — свой BillboardGui + TextLabel с текстом ?.

  • StudsOffset = 0, 3, 0
  • AlwaysOnTop = true
  • MaxDistance = 40 (метка только рядом — интереснее искать)

Положи сундуки в разных углах острова.

✨ Фаза 3 — Скрипт сбора 14 мин

В папку QuestIsland положи Script ChestScript. При касании сундука метка меняется на «✓» и отключается через пару секунд.

local folder = script.Parent

local function setupChest(chest)
  local gui = chest:FindFirstChild("BillboardGui")
  if not gui then return end
  local label = gui:FindFirstChildWhichIsA("TextLabel")
  local taken = false

  chest.Touched:Connect(function(hit)
    if taken then return end
    if hit.Parent:FindFirstChild("Humanoid") then
      taken = true
      if label then label.Text = "✓" end
      chest.BrickColor = BrickColor.new("Bright green")
      print("Сундук найден: " .. chest.Name)
      task.wait(2)
      gui.Enabled = false
    end
  end)
end

setupChest(folder.Chest1)
setupChest(folder.Chest2)
setupChest(folder.Chest3)
🔍
Снова FindFirstChild: ищем BillboardGui и Humanoid. gui.Enabled = false прячет метку после сбора.
