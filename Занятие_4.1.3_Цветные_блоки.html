⛲ Фонтан блоков

Фонтан + локация из Toolbox: текст, числа и цвет в коде

⛲
Мастерская фонтанов открыта! Сначала ты запрограммируешь радужный фонтан и выучишь три типа данных. А потом — построишь парк вокруг фонтана из готовых моделей Toolbox по техническому заданию. Получится целая локация: фонтан в центре и красивая площадь вокруг!

🎯 На этом уроке ты:

  • построишь модель фонтана из деталей в Roblox Studio 🏗️
  • научишься задавать текст — форму и материал блоков 📝
  • научишься задавать числа — прозрачность, отражение, случайность 🔢
  • научишься задавать цвет — BrickColor и Color3 🎨
  • запустишь радужный фонтан, который работает сам, без кнопок! ⛲
  • оформишь парк вокруг фонтана из моделей Toolbox 🌳

Ты узнаешь:

  • что такое текстовый, числовой и цветовой типы данных,
  • какие свойства Part используют каждый из типов.

Ты научишься:

  • строить модель и привязывать к ней скрипт,

  • собирать локацию по техническому заданию.

Что такое текстовый тип? Как задать цвет блоку? Что делает Transparency? Как использовать Toolbox?

0 Теория: три типа данных

string Текстовый тип

Текст всегда пишется в кавычках. В Roblox им задают названия форм, материалов, имён объектов.

-- текст (string)
part.Shape = "Ball"
part.Material = "Neon"
local name = "Мой фонтан"

Правило: если видишь кавычки — это текст.

number Числовой тип

Числа пишутся без кавычек. Целые и дробные: 0, 0.5, 1.

-- число (number)
part.Transparency = 0.5 -- 0 = видно, 1 = невидимо
part.Reflectance = 1 -- 0 = матовый, 1 = зеркало
wait(0.3) -- пауза 0.3 секунды

Color3 Цветовой тип

Цвет — отдельный тип. Можно задать названием (BrickColor) или тремя числами R, G, B (Color3).

-- цвет (BrickColor / Color3)
part.BrickColor = BrickColor.new("Bright red")
part.BrickColor = BrickColor.random()
part.Color = Color3.fromRGB(34, 26, 98)

🏗️ Фаза 1 — Строим модель фонтана 10 мин

Создай модель Fountain (Insert → Model). Внутри — 4 детали:

  1. Base — широкий блок-основание (Anchored = true).
  2. Pedestal — столбик посередине.
  3. Bowl — чаша сверху (можно Cylinder, повёрнутый горизонтально).
  4. Spawner — маленький невидимый Part над чашей (Transparency = 1) — отсюда вылетают блоки.

📝 Фаза 2 — Текстовый тип: форма блоков 10 мин

Создай скрипт FountainScript в ServerScriptService. Напиши цикл, который создаёт блоки над Spawner.

Здесь ты используешь текст: "Part", "Ball", "Cylinder".

local spawner = workspace.Fountain.Spawner

while true do
  wait(0.4)
  local part = Instance.new("Part", workspace) -- текст!
  part.Position = spawner.Position + Vector3.new(0, 2, 0)
  part.Anchored = false
  part.Shape = "Ball" -- текст! попробуй "Cylinder"
end
📖 Подсказка: зачем кавычки? "Ball" — это текст (string). Без кавычек Roblox подумает, что Ball — имя переменной, и выдаст ошибку.

🔢 Фаза 3 — Числовой тип: прозрачность и блеск 12 мин

Добавь в скрипт числа — прозрачность и отражение. Потом сделай случайную прозрачность через math.random.

  part.Shape = "Ball"
  part.Transparency = 0.5 -- число! полупрозрачный
  part.Reflectance = 1 -- число! зеркальный
  -- замени на случайное:
  part.Transparency = math.random(30, 80) / 100 -- от 0.3 до 0.8
📖 Подсказка: math.random math.random(30, 80) возвращает целое число от 30 до 80. Делим на 100 — получаем дробь от 0.3 до 0.8.

🎨 Фаза 4 — Цветовой тип: радуга 10 мин

Сначала случайный цвет через BrickColor.random(), потом — точный цвет через Color3.fromRGB.

-- вариант 1: случайный цвет
part.BrickColor = BrickColor.random()

-- вариант 2: свой цвет из трёх чисел
part.Color = Color3.fromRGB(
  math.random(0, 255),
  math.random(0, 255),
  math.random(0, 255)
)

🌙 Фаза 5 — Финал: ночь и Neon 8 мин

Добавь в начало скрипта ночь и материал Neon — фонтан засияет!

game.Lighting.ClockTime = 0 -- число! ночь
local spawner = workspace.Fountain.Spawner

while true do
  wait(0.4)
  local part = Instance.new("Part", workspace)
  part.Position = spawner.Position + Vector3.new(0, 2, 0)
  part.Anchored = false
  part.Shape = "Ball"
  part.Material = "Neon" -- текст! светится
  part.Color = Color3.fromRGB(math.random(0,255), math.random(0,255), math.random(0,255))
  part.Transparency = math.random(30, 80) / 100
  part.Reflectance = 1
end
⛲ Часть 1 готова! Фонтан работает — переходи к оформлению парка из Toolbox.

🌳 Часть 2 — Парк у фонтана (Toolbox)

Фонтан запрограммирован — теперь оформи локацию вокруг него. Все объекты бери из Toolbox (View → Toolbox) и расставляй в зоне ParkZone. Фонтан — в центре, вокруг — уютный парк по ТЗ ниже.

💡
Как работать с Toolbox:
  1. Открой View → Toolbox (или вкладка Toolbox справа).
  2. Ищи модели на английском: bench, tree, lamp, path, fence.
  3. Кликни по модели — она появится в Workspace. Перетащи в зону ParkZone.
  4. Инструменты Move и Rotate — чтобы красиво расставить.
  5. У каждого объекта поставь Anchored = true, чтобы не упали.

Создай папку FountainPark в Workspace и сложи туда все объекты парка (кроме самого Fountain).

🗺️ Фаза 6 — Собираем парк 25 мин

📖 Подсказка: что искать в Toolbox

Попробуй запросы: park bench, street lamp, oak tree, garden path, wooden fence, park sign. Выбирай модели с зелёной галочкой (проверенные создателем).

📖 Подсказка: как не сломать фонтан

Не ставь деревья и забор прямо над Spawner. Оставь «небо» над чашей свободным — иначе блоки будут застревать в моделях.

🎉 Готово! У тебя полноценная локация: программирование (фонтан) + моделирование (парк из Toolbox).

📜 Итоговый скрипт фонтана

Когда все фазы готовы — твой FountainScript должен выглядеть примерно так:

game.Lighting.ClockTime = 0
local spawner = workspace.Fountain.Spawner

while true do
  wait(0.4)
  local part = Instance.new("Part", workspace)
  part.Position = spawner.Position + Vector3.new(0, 2, 0)
  part.Size = Vector3.new(2, 2, 2)
  part.Anchored = false
  part.Shape = "Ball"
  part.Material = "Neon"
  part.Color = Color3.fromRGB(math.random(0,255), math.random(0,255), math.random(0,255))
  part.Transparency = math.random(30, 80) / 100
  part.Reflectance = 1
end
