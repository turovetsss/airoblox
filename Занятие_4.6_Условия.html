0 Теория: ветвления

🤔 Зачем нужны условия?

Без if скрипт всегда делает одно и то же. С условием он выбирает путь:

Монет ≥ 5? → ДА → открыть дверь → НЕТ → сказать «мало монет»

В жизни то же самое: «если дождь — зонт, иначе — кепка».

📐 Синтаксис if

local coins = 7

if coins >= 5 then
  print("Ворота открыты!")
end

⚠️
Условие должно быть истиной или ложью (boolean). Обычно это сравнение: coins >= 5, name == "Ключ", hasKey == true.

🔁 if + else — два пути

else = «иначе» — сработает, только если условие ложно.

if coins >= 5 then
  print("Проходи!")
else
  print("Мало монет")
end

Только if

Либо сделали действие, либо ничего.

if + else

Всегда один из двух путей.

📚 elseif — несколько проверок

Когда вариантов больше двух — ставим elseif (сколько угодно) и в конце else.

if coins >= 10 then
  print("VIP-проход!")
elseif coins >= 5 then
  print("Обычный проход")
else
  print("Недостаточно")
end
🔑
Порядок важен! Сначала проверяй более строгое условие (>= 10), потом мягкое (>= 5). Иначе «VIP» никогда не сработает.

🧠 Типичные ошибки

  • Написали if coins = 5 вместо == (одно = — присваивание!).
  • Забыли then или end.
  • Сравнивают Part с числом: door == 5 — бессмыслица. Сравнивай свойства: coins.Value >= 5.

🪙 Фаза 1 — Скрипт монет (CoinPad) 10 мин

Script внутри CoinPad:

local pad = script.Parent
local click = pad:WaitForChild("ClickDetector")
local coins = pad.Parent:WaitForChild("Coins")
local lamp = pad.Parent:WaitForChild("StatusLamp")

click.MouseClick:Connect(function(player)
  coins.Value = coins.Value + 1
  print(player.Name .. " монет: " .. coins.Value)

  -- цвет лампы по правилам if / elseif / else
  if coins.Value >= 10 then
    lamp.BrickColor = BrickColor.new("Lime green")
  elseif coins.Value >= 5 then
    lamp.BrickColor = BrickColor.new("New Yeller")
  else
    lamp.BrickColor = BrickColor.new("Really red")
  end
end)
💡
Здесь условие уже работает: лампа показывает уровень «готовности» ещё до клика по воротам.

🚪 Фаза 2 — Скрипт ворот (Gate) 14 мин

Script внутри Gate:

local gate = script.Parent
local click = gate:WaitForChild("ClickDetector")
local coins = gate.Parent:WaitForChild("Coins")
local closedPos = gate.Position
local openPos = closedPos + Vector3.new(0, 0, 8) -- сдвинь под свою карту
local isOpen = false

click.MouseClick:Connect(function(player)
  if isOpen then
    print("Уже открыто")
    return
  end

  if coins.Value >= 10 then
    print(player.Name .. " — VIP-проход!")
    gate.Position = openPos
    gate.BrickColor = BrickColor.new("Lime green")
    isOpen = true
  elseif coins.Value >= 5 then
    print(player.Name .. " — обычный проход")
    gate.Position = openPos
    gate.BrickColor = BrickColor.new("New Yeller")
    isOpen = true
  else
    print(player.Name .. " — мало монет! Нужно 5")
    gate.BrickColor = BrickColor.new("Really red")
  end
end)
🎯
Это сердце урока: три ветки if / elseif / else. Попробуй сначала с 3 монетами, потом с 5, потом с 10 — смотри Output.
