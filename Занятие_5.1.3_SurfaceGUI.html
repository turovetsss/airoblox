🖥️ ScreenGui vs 🪧 SurfaceGui

ScreenGui

Живёт в StarterGui → у каждого игрока на экране.

Меню, HP, кнопки «Играть».

SurfaceGui

Живёт внутри Part (или с Adornee на Part).

Вывеска на стене, табло, пульт в мире.

💡
SurfaceGui видят все, кто смотрит на эту грань Part — как настоящую табличку в комнате.

🧱 Как создать вывеску

  1. Создай Part (доска) — удобный размер около 8 × 4 × 1. Имя SignBoard.
  2. Anchored = true.
  3. В Part: Insert Object → SurfaceGui.
  4. В SurfaceGui: Insert Object → TextLabel (надпись) или TextButton (кнопка).

📐 Face — на какой стороне висит GUI?

У Part шесть граней. Свойство Face у SurfaceGui выбирает сторону:

Top
Front
Bottom
Left
Back
Right

По умолчанию — Front. Если надпись «смотрит в стену» — смени Face или поверни Part.

💡 LightInfluence — «неон ночью»

Обычно SurfaceGui затемняется вместе с миром. Для яркой вывески:

  • LightInfluence = 1 — как освещение вокруг (по умолчанию)
  • LightInfluence = 0 — всегда яркий, как неон
✨
Поставь LightInfluence = 0 на вывеске кафе — ночью она будет светиться!

🔘 Кнопки на SurfaceGui

Можно положить TextButton внутрь SurfaceGui. Надёжный способ для урока:

  • на Part с кнопкой добавь ещё ClickDetector;
  • в Script лови MouseClick и меняй текст на SurfaceGui / открывай дверь.

Так клик работает стабильно, а SurfaceGui делает панель красивой.

🧱 Фаза 0 — Фасад кафе 10 мин

  1. Создай папку Cafe в Workspace.
  2. Собери стену Wall (широкий Part) и рядом Door (дверь, Anchored).
  3. В Door добавь BoolValue IsOpen = false.
  4. Поставь SpawnLocation перед входом.

🪧 Фаза 1 — Неоновая вывеска 12 мин

  1. Part SignBoard на фасаде (примерно 8×3×1).
  2. Внутрь → SurfaceGui → TextLabel с текстом КАФЕ РОБО.
  3. На SurfaceGui: LightInfluence = 0, Face = Front.
  4. У TextLabel: Настрой свойства, выделенные на картинках зеленым цветом на свой вкус
✨
Если надпись не видна — повернись к Front или смени Face. Ночью (Lighting) проверь, что вывеска не гаснет.

📋 Фаза 2 — Меню на стене 12 мин

Part MenuBoard рядом со входом. Один SurfaceGui, внутри три TextLabel:

  • Item1 — «🍕 Пицца — 10»
  • Item2 — «🧃 Сок — 5»
  • Item3 — «🍰 Торт — 8»

Расположи их столбиком (разный Position.Y). У SurfaceGui LightInfluence можно 0 или 0.3.

    Item1, Item2, Item3

🛎️ Фаза 3 — Пульт заказа 14 мин

  1. Part OrderPanel у стойки (или на стене).
  2. Добавь ClickDetector.
  3. SurfaceGui → TextButton (или TextLabel) с именем OrderBtn, текст ЗАКАЗАТЬ.
  4. Ещё один TextLabel Status — сначала пустой или «Ждём заказ».

Script внутри OrderPanel:

local panel = script.Parent
local gui = panel:WaitForChild("SurfaceGui")
local status = gui:WaitForChild("Status")
local door = workspace.Cafe:WaitForChild("Door")
local isOpen = door:WaitForChild("IsOpen")

panel.ClickDetector.MouseClick:Connect(function()
  status.Text = "Заказ принят! ☕"
  isOpen.Value = true
  door.Transparency = 0.6
  door.CanCollide = false
  print("Дверь кафе открыта")
end)
🛎️
SurfaceGui рисует кнопку, ClickDetector ловит клик. Вместе получается «умный» пульт в мире.

🚪 Фаза 4 — Закрыть кафе + проверка 10 мин

Добавь на тот же пульт второй «режим»: повторный клик закрывает дверь.

panel.ClickDetector.MouseClick:Connect(function()
  if isOpen.Value == false then
    status.Text = "Заказ принят! ☕"
    isOpen.Value = true
    door.Transparency = 0.6
    door.CanCollide = false
  else
    status.Text = "Кафе закрыто"
    isOpen.Value = false
    door.Transparency = 0
    door.CanCollide = true
  end
end)

Замени предыдущий обработчик этим (один Connect).

🎉 Базовое кафе готово! Дальше — доп. фазы, потом ТЗ на здание.

🔄 Фаза 5 (доп) — Вывеска с двух сторон 8 мин

Скопируй SurfaceGui на SignBoard (Ctrl+D). У копии поставь Face = Back и текст, например OPEN или своё имя кафе.

🎨 Фаза 6 (доп) — Цвета и «сегодняшнее блюдо» 8 мин

  1. Покрась пункты меню в разные цвета TextColor3.
  2. Добавь на MenuBoard TextLabel Special — «Сегодня: Пицца».
  3. В скрипте заказа при открытии меняй Special на «Заказ в работе!» (через MenuBoard.SurfaceGui.Special.Text = ...).

🏗️ Часть 2 — Достройка здания кафе

Скрипты и SurfaceGui уже работают. Теперь по техническому заданию дострой полноценное здание и улицу вокруг — из своих Parts и/или моделей из Toolbox (только декор, без новых скриптов).

📁
Создай (или используй) папку Cafe в Workspace. Внутри заведи подпапку Building — туда сложи стены, крышу, окна, мебель и декор. Уже готовые SignBoard, MenuBoard, OrderPanel, Door не ломай — они остаются на фасаде.

📋 Техническое задание: здание «КАФЕ РОБО»

🧱
Коробка здания
Пол + 4 стены + крыша (минимум 6 Parts) или готовая модель здания из Toolbox. Дверь Door остаётся на фасаде / в проёме.
🪟
Окна
Минимум 2 окна: полупрозрачные Part (Transparency ≈ 0.4–0.6) или модели Window из Toolbox.
🛤️
Дорожка ко входу
От SpawnLocation до Door — дорожка из 3+ плит (Path / Brick).
🪑
Летняя терраса
Снаружи: минимум 1 столик + 2 стула (Parts или Toolbox: table, chair).
🛋️
Интерьер
Внутри: стойка/барная стойка + 1–2 предмета (стул гостя, полка, касса — на выбор).
💡
Освещение
Минимум 2 источника света: фонарь у входа и лампа внутри (Part + PointLight). Ночью кафе должно быть видно.
🌳
Озеленение
2+ дерева / куста / кашпо у фасада (Toolbox: tree, bush, plant).
🚧
Ограда террасы
Низкий забор или бордюр вокруг летней зоны (fence / barrier).
🏷️
Табличка «Цены внутри»
Ещё один Part + SurfaceGui + TextLabel «Цены внутри» на боковой стене (Face правильный, LightInfluence = 0).
🕐
Часы работы
Маленькая вывеска SurfaceGui: «10:00 – 22:00» или свой график рядом с входом.
