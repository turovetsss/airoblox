✨ Что такое Tween?

Tween (от «between» — между) — плавный переход от одного состояния к другому.

  • было слева → стало в центре (положение)
  • было маленьким → стало большим (размер)
  • было за экраном → выехало вниз (меню)
💡
Без Tween: панель «телепортируется». С Tween: как в настоящих играх — выезжает, пружинит, увеличивается.

📐 Три главных метода

TweenPosition

Только положение

:TweenPosition(куда)

TweenSize

Только размер

:TweenSize(какой)

TweenSizeAndPosition

И размер, и место

:TweenSizeAndPosition(size, pos)

Позиция и размер задаются через UDim2 (как обычно в GUI):

UDim2.new(0.5, 0, 0.1, 0)
-- X scale, X offset, Y scale, Y offset

▶️ Простой пример: выезд в центр

local panel = script.Parent
panel.AnchorPoint = Vector2.new(0.5, 0.5)
panel.Position = UDim2.new(0.5, 0, -0.5, 0) -- выше экрана

task.wait(1)
panel:TweenPosition(UDim2.new(0.5, 0, 0.5, 0))

Сначала панель спрятана сверху, потом плавно едет в центр.

🎛️ Параметры анимации

После цели можно указать стиль:

panel:TweenPosition(
  UDim2.new(0.5, 0, 0.1, 0),
  Enum.EasingDirection.Out,
  Enum.EasingStyle.Quint,
  0.5 -- секунды
)
ПараметрЧто делает
EasingDirectionIn — медленный старт; Out — мягкий финиш; InOut — оба
EasingStyleХарактер: Linear, Quad, Quint, Bounce, Back, Elastic…
ВремяСколько секунд длится анимация (часто 0.3–1)

Популярные стили для меню:

Out + Quint — гладко Out + Bounce — прыжок Out + Back — чуть «отскок» Linear — ровно
📝
В старых примерах пишут строки "Out", "Quint". В новых — Enum.EasingDirection.Out. Оба варианта часто работают; на уроке можно копировать код с Enum.

🖥️ Фаза 0 — Каркас GUI 10 мин

  1. StarterGui → ScreenGui BagGUI.
  2. Frame Inventory: Size примерно {0.5, 0},{0.35, 0}, AnchorPoint = 0.5, 0.
  3. Начальная Position: {0.5, 0}, {0, -250} или scale Y отрицательный — панель над экраном.
  4. TextButton OpenBtn внизу экрана (отдельно от Inventory) — «🎒 Открыть».

🧩 Фаза 1 — Содержимое инвентаря 10 мин

  1. В Inventory: TextLabel Title Text — «Инвентарь».
  2. Три Frame или TextButton: Slot1, Slot2, Slot3 (ячейки).
  3. TextButton CloseBtn — «Закрыть» внутри Inventory.

⬇️ Фаза 2 — Tween: открыть 12 мин

LocalScript в BagGUI:

local gui = script.Parent
local inventory = gui:WaitForChild("Inventory")
local openBtn = gui:WaitForChild("OpenBtn")
local closeBtn = inventory:WaitForChild("CloseBtn")

local hidden = UDim2.new(0.5, 0, 0, -250)
local shown = UDim2.new(0.5, 0, 0.8, 0)

inventory.AnchorPoint = Vector2.new(0.5, 0)
inventory.Position = hidden

openBtn.MouseButton1Click:Connect(function()
  inventory:TweenPosition(
    shown,
    Enum.EasingDirection.Out,
    Enum.EasingStyle.Quint,
    0.5
  )
end)
⬇️
Две «точки»: hidden (где спрятано) и shown (куда выехать). Tween едет между ними.

⬆️ Фаза 3 — Tween: закрыть 8 мин

closeBtn.MouseButton1Click:Connect(function()
  inventory:TweenPosition(

🏀 Фаза 5 (доп) — Bounce при открытии 6 мин

В открытии замени стиль на Enum.EasingStyle.Bounce и время на 0.8. Панель «подпрыгнет».

📏 Фаза 6 (доп) — TweenSize на слоте 8 мин

По клику на Slot1 он плавно увеличивается на 20% и возвращается обратно. Используй этот код в LocalScript внутри gui.

local slot1 = inventory.Slot1
local normal = slot1.Size
local big = UDim2.new(
  normal.X.Scale * 1.2, normal.X.Offset * 1.2,
  normal.Y.Scale * 1.2, normal.Y.Offset * 1.2
)

slot1.MouseButton1Click:Connect(function()
  slot1:TweenSize(big, Enum.EasingDirection.Out, Enum.EasingStyle.Back, 0.2)
  task.wait(0.25)
  slot1:TweenSize(normal, Enum.EasingDirection.Out, Enum.EasingStyle.Quad, 0.2)
  task.wait(0.2)
end)
