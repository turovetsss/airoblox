Рубка дерева + копка руды + Terrain = простой «майнкрафт» в Roblox Studio

🌳
Миссия проекта: собрать два мини-симулятора и склеить их в один мир. Сначала — дерево и топор. Потом — блок руды и кирка. Затем — ландшафт Terrain, дубли деревьев и блоков: получается простой симулятор в стиле Minecraft.

📚 Теория: как устроен «симулятор»

1. Идея симулятора

В симуляторе игрок взаимодействует с миром инструментом: бьёт дерево топором, копает блок киркой. Объект «ломается» после нескольких ударов и оставляет дроп (дерево → Wood, руда → Gold).

🪓 Tool

Предмет в руке. Физическая часть удара почти всегда называется Handle.

❤️ Health

Счётчик ударов. Каждый касание Handle уменьшает здоровье на 1.

💎 Drop

Когда здоровье < 1 — создаём новый Part и уничтожаем оригинал.

2. Union — цельный блок

Дерево из цилиндра + сферы удобно склеить в один UnionOperation. Тогда скрипт висит на одном объекте, а Touched срабатывает по всему дереву.

💡
Model → Solid Modeling → Union. Выдели ствол и крону вместе (Ctrl), затем Union.

3. StarterPack

Всё, что лежит в StarterPack, появляется у игрока в инвентаре при входе. Топор и кирку перетаскиваем из Workspace в StarterPack.

4. Touched + Handle

Скрипт на дереве/блоке слушает Touched. Если коснувшийся объект называется Handle — это удар инструментом, а не просто касание ногой.

if object.Name == "Handle" then
  health -= 1
end

🌲 Часть A · Фаза 1 — Модель дерева 10 мин

  1. Вставь Part → Cylinder (ствол) и Part → Ball (крона).
  2. Покрась ствол в коричневый, крону в зелёный. Закрепи Anchor.
  3. Поставь сферу на цилиндр — должно получиться простое дерево.

Сначала форма: цилиндр + сфера на Baseplate.

После окраски: коричневый ствол и зелёная крона.

🔗 Часть A · Фаза 2 — Union 5 мин

  1. Выдели оба парты дерева (Ctrl + клик).
  2. Вкладка MODEL → раздел Solid Modeling → кнопка Union.
  3. Дерево стало одним цельным блоком (UnionOperation).

MODEL → Solid Modeling → Union (кнопка обведена).

🪓 Часть A · Фаза 3 — Топор из Toolbox 8 мин

  1. Открой Toolbox → Models → поиск axe.
  2. Выбери первую модель Axe Tool и вставь возле дерева.
  3. В Explorer перетащи Axe Tool из Workspace в папку StarterPack.

Toolbox → поиск «axe» → модель Axe Tool.

Топор стоит рядом с готовым деревом.

Перетащи Axe Tool → StarterPack (стрелка на скрине).

📜 Часть A · Фаза 4 — Скрипт рубки 15 мин

  1. Переименуй Union в tree.
  2. Добавь внутрь Script (не LocalScript).
  3. Вставь код ниже. Нажми Play и ударь дерево топором 5 раз.

Иерархия: tree (Union) → Script.

Ориентир по коду в редакторе Studio.

local tree = script.Parent
local tree_health = 5

local function onTouch(object)
    if object.Name == "Handle" then
        tree_health -= 1
        if tree_health < 1 then
            local drop = Instance.new("Part", workspace)
            drop.Position = tree.Position
            drop.Material = Enum.Material.Wood
            drop.Size = Vector3.new(1, 1, 1)
            drop.BrickColor = BrickColor.new("Brown")
            drop.Name = "Wood"
            print("Вы нашли " .. drop.Name)
            tree:Destroy()
        end
    end
end

tree.Touched:Connect(onTouch)
✅
После 5 ударов дерево исчезнет, в мире появится кубик Wood, в Output — «Вы нашли Wood».

⛏️ Часть B · Фаза 5 — Симулятор копателя 15 мин

  1. Создай обычный Part (куб руды). Покрась в жёлтый, Anchor = true.
  2. Сразу добавь внутрь Script.
  3. В Toolbox найди pickaxe tool → первая модель → в StarterPack.
  4. Проверь в Play: киркой бей блок 5 раз → появится Gold.

Part → Script (скрипт — дочерний объект блока).

Логика копки: здоровье → дроп Gold → Destroy.

Toolbox → «pickaxe tool» → Pickaxe tool.

В Play в хотбаре: Axe Tool и Pickaxe. Бей жёлтый куб киркой.

local part = script.Parent
local BlockHealth = 5

local function onTouch(object)
    print("Touch started: " .. object.Name)
    if object.Name == "Handle" then
        BlockHealth = BlockHealth - 1
        print(BlockHealth)
        if BlockHealth < 1 then
            local Drop = Instance.new("Part", workspace)
            Drop.Position = part.Position
            Drop.Material = Enum.Material.Metal
            Drop.Size = Vector3.new(1, 1, 1)
            Drop.BrickColor = BrickColor.Yellow()
            Drop.Name = "Gold"
            print("Вы нашли " .. Drop.Name)
            part:Destroy()
        end
    end
end

part.Touched:Connect(onTouch)
⚠️
Частый баг: Touched срабатывает много раз подряд, пока Handle касается блока. Для урока это ок (ломается быстро). Позже можно добавить задержку через debounce.

🗺️ Часть C · Фаза 6 — Мир Minecraft 20 мин

Теперь твоя задача — превратить песочницу в простой симулятор Minecraft:

  1. Открой Home → Editor → Terrain Editor (или вкладка Terrain).
  2. Нарисуй холмы, траву, ямы — живой ландшафт вместо плоского Baseplate.
  3. Скопируй дерево (Ctrl+D) несколько раз, расставь по миру.
  4. Аналогично продублируй блоки руды / камня.
  5. У каждого дубля должен быть свой Script (при дублировании скрипт копируется вместе с моделью).

Итог: трава, деревья, блоки, в инвентаре топор и кирка.

🏆 Если в мире несколько деревьев и руд, Terrain нарисован, оба инструмента работают — симулятор готов!

✨ Фаза 7 (доп) — Улучшения 15 мин

  • Сложи деревья в папку Trees, руду — в Ores.

  • Сделай разное здоровье: дерево = 5, камень = 8, золото = 10.
