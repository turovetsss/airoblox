0 Теория: парные циклы

📦 Сначала — массив (таблица)

В Lua список пишут в фигурных скобках. Индексы начинаются с 1:

local fruits = {"яблоко", "банан", "киви"}
-- fruits[1] = "яблоко", fruits[2] = "банан" …

В игре в массив кладут объекты:

local lights = {workspace.Light1, workspace.Light2, workspace.Light3}

🔄 Что такое парный цикл?

Цикл pairs проходит все элементы массива. На каждом шаге даёт две переменные:

  • i — индекс (номер: 1, 2, 3…)
  • v — значение (строка или сам объект Part)
for i, v in pairs(fruits) do
  print(i, v)
end
1  яблоко
2  банан
3  киви
💡
Имена могут быть любыми: for index, fruit in pairs(...). Часто пишут коротко i, v или _, part (если индекс не нужен).

🆚 Обычный for и pairs

for i = 1, n

Сам считаешь числа. Удобно «с конца» или каждый второй.

for i = 1, #lights do

for i, v in pairs

Сразу даёт и номер, и элемент. Удобно для списка объектов.

for i, v in pairs(lights)

💡 Пример: включить лампочки

local lights = {
  workspace.Light1,
  workspace.Light2,
  workspace.Light3,
  workspace.Light4
}

for i, lamp in pairs(lights) do
  lamp.Material = Enum.Material.Neon
  lamp.BrickColor = BrickColor.new("New Yeller")
  print("Включена лампа №" .. i)
  task.wait(0.5)
end

Один цикл — все лампы по очереди загораются.

📁 Бонус: GetChildren + pairs

Если лампы лежат в папке, массив можно не перечислять вручную:

local folder = workspace.Lights
for _, child in pairs(folder:GetChildren()) do
  if child:IsA("BasePart") then
    child.Material = Enum.Material.Neon
  end
end

💡 Фаза 0 — Собери лампы 10 мин

  1. Папка Lights в Workspace.
  2. 5 Part: Light1 … Light5 в ряд (Anchored).
  3. Можно разные цвета пока обычные Plastic.

🔄 Фаза 1 — Включение через pairs 12 мин

Script GarlandScript в ServerScriptService:

local lights = {
  workspace.Lights.Light1,
  workspace.Lights.Light2,
  workspace.Lights.Light3,
  workspace.Lights.Light4,
  workspace.Lights.Light5
}

for i, lamp in pairs(lights) do
  lamp.Material = Enum.Material.Neon
  lamp.BrickColor = BrickColor.new("New Yeller")
  print("Лампа " .. i .. " включена")
  task.wait(0.4)
end

🌈 Фаза 2 — Цветовая волна 12 мин

Добавь второй цикл (после первого) с разными цветами:

local colors = {
  "Bright red",
  "Bright orange",
  "New Yeller",
  "Lime green",
  "Cyan"
}

for i, lamp in pairs(lights) do
  lamp.BrickColor = BrickColor.new(colors[i])
  task.wait(0.3)
end
🌈
Индекс i связывает лампу и цвет: colors[i] — вот зачем нужна пара i и v!

🚪 Фаза 3 — Двери одним циклом 12 мин

  1. Папка Doors: Door1, Door2, Door3 (тёмные Part).
  2. После гирлянды открой все двери через pairs:
local doors = {
  workspace.Doors.Door1,
  workspace.Doors.Door2,
  workspace.Doors.Door3
}

for _, door in pairs(doors) do
  door.Transparency = 0.6
  door.CanCollide = false
  task.wait(0.5)
end
print("Все двери открыты!")

🔙 Фаза 5 (доп) — Выключение с конца 8 мин

Пройди массив задом наперёд обычным for:

for i = #lights, 1, -1 do
  local lamp = lights[i]
  lamp.BrickColor = BrickColor.new("Black")
  lamp.Material = Enum.Material.SmoothPlastic
  task.wait(0.3)
end
