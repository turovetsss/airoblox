⚡ Кликер

Энергия, апгрейды, RemoteEvent, ClickDetector — первая полноценная мини-игра

💎
Миссия проекта: сделать игру-кликер, как в популярных симуляторах. Игрок кликает по кнопке и по кристаллу в мире, копит энергию, покупает удвоитель и автокликер. Сервер считает очки — клиент только шлёт запросы и рисует GUI.

💡 На этом проекте ты:

  • соберёшь мир: ClickPart + ClickDetector 🧱
  • сделаешь GUI: энергия, клик, два апгрейда 🖥️
  • свяжешь клиент и сервер через RemoteEvent ⚡
  • напишешь leaderstats, магазин и эффект частиц ✨

🎮 Жанр за 30 секунд

Кликер — игра, где главное действие: нажал → получил очки. Потом очки тратишь на апгрейды, которые дают ещё больше очков. Цепочка бесконечная — поэтому важно, чтобы сервер хранил энергию (иначе читеры легко «накрутят» себе миллион).

🏗️ Три слоя нашей игры

Клиент (LocalScript)

Кнопки, текст энергии, анимация GUI. Шлёт: «я кликнул / хочу купить».

Мост (RemoteEvent)

ClickEvent, BuyDoubleClick, BuyAutoClicker в ReplicatedStorage.

Сервер (Script)

leaderstats, сила клика, цены, автокликер, цвет Part.

Кнопка GUI → FireServer → OnServerEvent → Energy += power

🧱 Фаза 1 — ClickPart + ClickDetector 8 мин

  1. В Workspace создай Part, назови ClickPart.
  2. Свойства:
    • Size = (5, 5, 5)
    • Material = Plastic или Neon
    • Anchored = true
  3. Внутрь ClickPart добавь ClickDetector (ПКМ → Insert Object → ClickDetector).

Так должно выглядеть в Explorer: ClickPart → ClickDetector.

🖥️ Фаза 4 — MainScript на сервере 18 мин

  1. ServerScriptService → Script → имя MainScript.
  2. Сотри шаблон и вставь код ниже целиком.

MainScript живёт только в ServerScriptService (обычный Script, не LocalScript).

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

-- Храним данные игроков
local playerData = {}

-- Цвета для парта
local colors = {
  Color3.new(1, 0, 0), -- Красный
  Color3.new(0, 1, 0), -- Зеленый
  Color3.new(0, 0, 1), -- Синий
  Color3.new(1, 1, 0), -- Желтый
  Color3.new(1, 0, 1), -- Фиолетовый
  Color3.new(0, 1, 1) -- Голубой
}

local function setupPlayer(player)
  local leaderstats = Instance.new("Folder")
  leaderstats.Name = "leaderstats"
  leaderstats.Parent = player

  local energy = Instance.new("IntValue")
  energy.Name = "Energy"
  energy.Value = 0
  energy.Parent = leaderstats

  playerData[player] = {
    clickPower = 2,
    hasDouble = false,
    hasAutoClicker = false,
    doublePrice = 100,
    autoClickerPrice = 200,
    colorIndex = 1
  }
end

-- Клики по кнопке GUI
ReplicatedStorage.ClickEvent.OnServerEvent:Connect(function(player)
  if playerData[player] then
    local data = playerData[player]
    local energy = player.leaderstats.Energy
    energy.Value = energy.Value + data.clickPower
  end
end)

-- Клики по парту
local clickPart = workspace:FindFirstChild("ClickPart")
if clickPart then
  local clickDetector = clickPart:FindFirstChildOfClass("ClickDetector")
  if clickDetector then
    clickDetector.MouseClick:Connect(function(player)
      if playerData[player] then
        local data = playerData[player]
        local energy = player.leaderstats.Energy
        energy.Value = energy.Value + data.clickPower
        data.colorIndex = (data.colorIndex % #colors) + 1
        clickPart.BrickColor = BrickColor.new(colors[data.colorIndex])
        clickPart.Size = Vector3.new(5.2, 5.2, 5.2)
        wait(0.1)
        clickPart.Size = Vector3.new(5, 5, 5)
      end
    end)
  end
end

-- Покупка удвоителя
ReplicatedStorage.BuyDoubleClick.OnServerEvent:Connect(function(player)
  local data = playerData[player]
  local energy = player.leaderstats.Energy
  if data and energy.Value >= data.doublePrice then
    energy.Value = energy.Value - data.doublePrice
    data.clickPower = data.clickPower * 2
    data.hasDouble = true
    data.doublePrice = data.doublePrice * 2
    print(player.Name .. " купил удвоитель! Теперь клик: " .. data.clickPower)
  end
end)

-- Покупка автокликера
ReplicatedStorage.BuyAutoClicker.OnServerEvent:Connect(function(player)
  local data = playerData[player]
  local energy = player.leaderstats.Energy
  if data and energy.Value >= data.autoClickerPrice then
    energy.Value = energy.Value - data.autoClickerPrice
    data.hasAutoClicker = true
    data.autoClickerPrice = data.autoClickerPrice * 2
    spawn(function()
      while data.hasAutoClicker and player.Parent do
        wait(1)
        energy.Value = energy.Value + data.clickPower
      end
    end)
    print(player.Name .. " купил автокликер!")
  end
end)

Players.PlayerAdded:Connect(setupPlayer)
Players.PlayerRemoving:Connect(function(player)
  playerData[player] = nil
end)
🔑
Что делает сервер: создаёт Energy, слушает три RemoteEvent, считает клики по Part, удваивает силу, запускает автокликер раз в секунду.

📱 Фаза 5 — LocalScript в MainGUI 14 мин

  1. Внутри MainGUI создай LocalScript (не обычный Script!).
  2. Вставь клиентский код.

LocalScript должен лежать внутри MainGUI (выделен синим).

local Players = game:GetService("Players")
local player = Players.LocalPlayer
local screenGui = script.Parent
local energyText = screenGui.EnergyText
local clickButton = screenGui.ClickButton
local doubleUpgrade = screenGui.DoubleUpgrade
local autoClicker = screenGui.AutoClicker

local function updateUI()
  if player:FindFirstChild("leaderstats") then
    local energy = player.leaderstats.Energy.Value
    energyText.Text = " Энергия: " .. energy
    doubleUpgrade.Text = "Удвоитель кликов"
    autoClicker.Text = "Автокликер"
  end
end

clickButton.MouseButton1Click:Connect(function()
  game.ReplicatedStorage.ClickEvent:FireServer()
  clickButton.Size = UDim2.new(0, 140, 0, 55)
  wait(0.1)
  clickButton.Size = UDim2.new(0, 150, 0, 60)
end)

doubleUpgrade.MouseButton1Click:Connect(function()
  game.ReplicatedStorage.BuyDoubleClick:FireServer()
end)

autoClicker.MouseButton1Click:Connect(function()
  game.ReplicatedStorage.BuyAutoClicker:FireServer()
end)

doubleUpgrade.MouseEnter:Connect(function()
  doubleUpgrade.Text = "Удвоитель кликов\n(Удваивает силу клика)"
end)
doubleUpgrade.MouseLeave:Connect(function()
  doubleUpgrade.Text = "Удвоитель кликов"
end)

autoClicker.MouseEnter:Connect(function()
  autoClicker.Text = "Автокликер\n(Автоматические клики)"
end)
autoClicker.MouseLeave:Connect(function()
  autoClicker.Text = "Автокликер"
end)

while true do
  updateUI()
  wait(0.1)
end
👆
Клиент не пишет energy.Value = …. Он только делает FireServer() и читает уже готовое значение для надписи.
