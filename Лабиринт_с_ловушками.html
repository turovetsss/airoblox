🌀 Лабиринт с ловушками

Таймер, финиш, ловушки-телепорты и стены-обманки

🏁
Миссия проекта: взять лабиринт из Toolbox (или построить свой), поставить Finish с таймером, расставить ловушки Trap* (возврат на старт) и стены-проходы Wall* (исчезают при касании). Добавь пасхалки из Toolbox — и гонка готова!

💡 На этом проекте ты:

  • поставишь финиш и сделаешь таймер в GUI ⏱️
  • научишься телепортировать на старт через MoveTo 📍
  • отличишь ловушку от стены-прохода по имени и скрипту 🧱
  • расставишь объекты по лабиринту и украсишь мир ✨

📚 Теория

1. Три механики лабиринта

🏁 Finish

Касание → считаем время → поздравление → респавн.

⚠️ Trap

Имя содержит Trap → телепорт на старт + звук.

👻 Wall

Имя содержит Wall → становится невидимой и проходимой.

2. Имена важны

Скрипт ловушек ищет объекты, у которых в имени есть Trap или Ловушка. Скрипт стен — у кого есть Wall. Поэтому Trap1, Trap2, Wall, Wall2 — все подхватятся.

3. Позиция старта

В скрипте ловушек есть строка Vector3.new(...). Скопируй Position у своего SpawnLocation и вставь туда — иначе телепорт улетит «в космос».

🗺️ Фаза 1 — Лабиринт 10 мин

  1. Открой Toolbox → Models → поиск maze.
  2. Вставь бесплатную модель лабиринта (или построй стены сам).
  3. Поставь SpawnLocation у входа в лабиринт.

🏁 Фаза 2 — Finish и таймер 15 мин

  1. Создай Part на финише → Rename → Finish.
  2. Добавь Script в Workspace (или ServerScriptService) и вставь код таймера.
  3. Play: таймер тикает, касание Finish показывает результат.

Плита финиша в конце лабиринта.

Имя Part должно быть точно Finish.

Script лежит в Workspace (или ServerScriptService).

-- Script: таймер + финиш (Workspace / ServerScriptService)
local Players = game:GetService("Players")
local playerTimes = {}

Players.PlayerAdded:Connect(function(player)
    playerTimes[player] = os.time()

    local screenGui = Instance.new("ScreenGui")
    screenGui.Name = "SimpleTimer"
    screenGui.Parent = player:WaitForChild("PlayerGui")

    local textLabel = Instance.new("TextLabel")
    textLabel.Name = "TimerText"
    textLabel.Size = UDim2.new(0, 200, 0, 50)
    textLabel.Position = UDim2.new(0, 10, 0, 10)
    textLabel.Text = "Время: 0 сек"
    textLabel.TextColor3 = Color3.new(1, 1, 1)
    textLabel.BackgroundColor3 = Color3.new(0, 0, 0)
    textLabel.BackgroundTransparency = 0.5
    textLabel.Parent = screenGui

    while player.Parent do
        if playerTimes[player] then
            local timePassed = os.time() - playerTimes[player]
            textLabel.Text = "Время: " .. timePassed .. " сек"
        end
        wait(1)
    end
end)

local finish = workspace:WaitForChild("Finish")
finish.Touched:Connect(function(hit)
    local player = Players:GetPlayerFromCharacter(hit.Parent)
    if player and playerTimes[player] then
        local finishTime = os.time() - playerTimes[player]

        local resultGui = Instance.new("ScreenGui")
        resultGui.Name = "Result"
        resultGui.Parent = player.PlayerGui

        local resultText = Instance.new("TextLabel")
        resultText.Size = UDim2.new(0, 300, 0, 100)
        resultText.Position = UDim2.new(0.5, -150, 0.5, -50)
        resultText.Text = "УРА!\nТвое время: " .. finishTime .. " секунд"
        resultText.TextColor3 = Color3.new(1, 1, 0)
        resultText.TextSize = 20
        resultText.BackgroundColor3 = Color3.new(0, 0, 0)
        resultText.BackgroundTransparency = 0.3
        resultText.Parent = resultGui

        wait(3)
        resultGui:Destroy()

        local character = player.Character
        if character then
            local humanoid = character:FindFirstChild("Humanoid")
            if humanoid then
                humanoid.Health = 0
            end
        end
        playerTimes[player] = nil
    end
end)

⚠️ Фаза 3 — Ловушки Trap 18 мин

  1. Создай Part-стену в коридоре, покрась как стены лабиринта.
  2. Rename → Trap1.
  3. Добавь Script (код ниже). Лучше один общий скрипт в Workspace/ServerScriptService — он найдёт все Trap*.
  4. Скопируй Position у SpawnLocation → вставь в Vector3.new(...).
  5. Продублируй ловушки (Trap2, Trap3…) и расставь по лабиринту.

Стена-ловушка перекрывает проход.

Можно положить Script в Trap1 — или один общий в Workspace.

Properties → Position у SpawnLocation — скопируй X, Y, Z.

Замени координаты в строке startPosition на свои.

🎓 Важно: скрипт один на все ловушки. Если продублировать Trap вместе со Script, подписки задвоятся — оставь Script только в одном месте.
-- Script ловушек (один раз в Workspace / ServerScriptService)
local Players = game:GetService("Players")

-- Стартовая позиция (измени на свою!)
local startPosition = Vector3.new(-30, 17.247, 40)

for _, trap in pairs(workspace:GetChildren()) do
    if trap.Name:find("Trap") or trap.Name:find("Ловушка") then
        trap.Touched:Connect(function(hit)
            local humanoid = hit.Parent:FindFirstChild("Humanoid")
            if humanoid then
                hit.Parent:MoveTo(startPosition)

                local sound = Instance.new("Sound")
                sound.SoundId = "rbxassetid://100600468769372"
                sound.Parent = trap
                sound:Play()
                wait(2)
                sound:Destroy()
            end
        end)
        print("Ловушка '" .. trap.Name .. "' настроена!")
    end
end

print("Все ловушки готовы!")

👻 Фаза 4 — Стены-проходы Wall 15 мин

  1. Создай Part, внешне как ловушка (чтобы путать игрока).
  2. Rename → Wall (или Wall2, Wall3…).
  3. Один общий Script ищет все объекты с Wall в имени.
  4. Расставь исчезающие стены по лабиринту рядом с ловушками.

Стена-проход выглядит как обычная преграда.

Wall → Script (или один общий скрипт в Workspace).

-- Script исчезающих стен (один раз)
for _, wall in pairs(workspace:GetChildren()) do
    if wall.Name:find("Wall") and wall:IsA("BasePart") then
        wall.Touched:Connect(function(hit)
            local humanoid = hit.Parent:FindFirstChild("Humanoid")
            if humanoid then
                wall.Transparency = 1
                wall.CanCollide = false

                local sound = Instance.new("Sound")
                sound.SoundId = "rbxassetid://100600468769372"
                sound.Parent = wall
                sound:Play()
                wait(2)
                sound:Destroy()
                print("Стена '" .. wall.Name .. "' исчезла!")
            end
        end)
        print("Исчезающая стена '" .. wall.Name .. "' настроена!")
    end
end

print("Все исчезающие стены готовы!")
⚠️
В черновике иногда пишут light.Enabled = false — без объекта Light это даст ошибку. В рабочем коде выше этой строки нет.
