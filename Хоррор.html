💡
В Explorer сервис называется Lighting (не Lightning). TimeOfDay и FogEnd — его свойства.

2. Вид от первого лица

В FP Roblox прячет тело игрока через LocalTransparencyModifier. Скрипт каждый кадр (RenderStepped) ставит его в 0 для рук или ног — и они снова видны.

3. Спринт

LocalScript в StarterGui: при зажатии клавиши поднимаем WalkSpeed до 50 и чуть увеличиваем FieldOfView. При отпускании — обратно 16.

🌿 Фаза 1 — Земля и локация 20 мин

  1. Создай Part, растяни Move/Scale на всю площадку.
  2. Properties: зелёный цвет, Material = Grass, включи Anchor.
  3. Toolbox → Cabin — поставь домик(и).
  4. Toolbox → Forest / Trees — лес. По желанию вышки с светом.
  5. Toolbox → Horror Sky — перетащи тёмный Skybox на экран.
  6. Explorer → Lighting: TimeOfDay = 02:00:00, FogEnd = 1000.

Ночь, туман, лес и постройки — общий план.

🔦 Фаза 2 — Спавн, фонарик, киллер 12 мин

  1. Toolbox → SpawnLocation — возле дома.
  2. Toolbox → Flashlight — рядом со спавном (подхватить сразу).
  3. Toolbox → Killer → Jason The Killer (или другой). Расставь сколько хочешь.
  4. Play: киллер бежит за героем.

Дом в тумане + SpawnLocation на крыльце.

Killer на карте рядом с хижиной.

👀 Фаза 3 — Вид от 1-го лица (руки и ноги) 15 мин

  1. Explorer → StarterPlayer → StarterPlayerScripts → «+» → LocalScript.
  2. Переименуй в ArmFPview, вставь код рук.
  3. Скопируй скрипт → второй LocalScript LegFPview: Arm/Hand → Leg/Foot.
  4. Play: приблизь камеру колёсиком — видны руки и ноги.

StarterPlayer → StarterPlayerScripts.

ArmFPview — руки и кисти.

-- ArmFPview (LocalScript в StarterPlayerScripts)
local player = game:GetService("Players").LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()

game:GetService("RunService").RenderStepped:Connect(function()
    for i, part in pairs(character:GetChildren()) do
        if string.match(part.Name, "Arm") or string.match(part.Name, "Hand") then
            part.LocalTransparencyModifier = 0
        end
    end
end)

Проверка: руки видны от первого лица.

LegFPview — то же для Leg и Foot.

-- LegFPview (второй LocalScript)
local player = game:GetService("Players").LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()

game:GetService("RunService").RenderStepped:Connect(function()
    for i, part in pairs(character:GetChildren()) do
        if string.match(part.Name, "Leg") or string.match(part.Name, "Foot") then
            part.LocalTransparencyModifier = 0
        end
    end
end)

Ноги видны; фонарик лежит у ног у спавна.

🏃 Фаза 4 — Спринт от киллера 12 мин

  1. StarterGui → «+» → LocalScript (спринт).
  2. Вставь код: зажатие клавиши → WalkSpeed 50 + FOV; отпускание → 16.
  3. Play: удирай от киллера на всех парах.
  4. Добавь ещё противников и предметы самостоятельно!

StarterGui → добавить LocalScript.

Спринт: KeyDown / KeyUp, WalkSpeed и FieldOfView.

-- LocalScript в StarterGui
local Mos = game.Players.LocalPlayer:GetMouse()

-- если клавиша нажата
Mos.KeyDown:Connect(function(key)
    if key == string.char(48) then
        game.Workspace.CurrentCamera.FieldOfView =
            game.Workspace.CurrentCamera.FieldOfView + 1.6
        game.Players.LocalPlayer.Character:FindFirstChild("Humanoid").WalkSpeed = 50
    end
end)

-- Если клавиша отпущена
Mos.KeyUp:Connect(function(key)
    if key == string.char(48) then
        game.Workspace.CurrentCamera.FieldOfView =
            game.Workspace.CurrentCamera.FieldOfView - 1.6
        game.Players.LocalPlayer.Character:FindFirstChild("Humanoid").WalkSpeed = 16
    end
end)
⚠️
В уроке используется string.char(48) — как в методичке. Если спринт не ловится на твоей клавиатуре — попроси педагога проверить раскладку / клавишу.
